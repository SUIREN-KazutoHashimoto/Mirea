# 0.18.1beta

一般アカウントからも、エラー発生時の安全な診断情報を表示・コピーできます。確認ダイアログを閉じずに「エラーの詳細を見る」を押すか、「設定 → エラーの詳細を開く」へ進んでください。

[診断情報・マスキング・保持範囲の説明](error-diagnostics.md)を参照してください。マスク済み情報の作成は許可リスト方式です。例外の原文やサーバーの生ログをクライアントへ送る機能ではありません。

- 内部版0.18.1-beta、APK版0.18.1beta／code36。配布署名は従来のものを維持します。
- データベースはschema20のままで、データ構造の移行はありません。
- 更新前にdata・media・設定・証明書を一式バックアップしてください。
- Web/PWAとAPKは別のクライアントです。APKの同梱画面を更新するには新APKへの更新が必要です。
- シリーズ削除の実環境の問題は原因未特定です。エラーが再発したら詳細をコピーしてください。削除成功を保証する修正とは区別しています。
- TrueNASはCodexの検証環境として使用しません。検証にはLAN上の隔離した合成データを使います。
- Play Protectの判定解除は確認していません。保護機能の無効化は行いません。
