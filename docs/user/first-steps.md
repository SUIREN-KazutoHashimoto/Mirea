# Mireaを使い始める

Mireaは、本・動画・音楽をサーバーにまとめ、PCやスマートフォンから楽しむためのライブラリです。このページでは、接続して最初の作品を開くところまでを説明します。

> 対象は Mirea `1.0.0` です。[文書一覧](../README.md)

## 1. 自分に合う入口を選ぶ

| 状況 | 最初にすること |
| --- | --- |
| 自分でサーバーを設置したい | [導入方法を選ぶ](../install/choose.md)へ進む。アプリだけではサーバーは作成されません。 |
| 設置済みのサーバーを使いたい | 管理者から接続URLと、登録方法の案内を受け取る。 |
| PCで使っていて、スマートフォンでも使いたい | 同じ接続URLと、同じアカウントを使う。 |

URLの例は `https://media.example.com` です。ポート番号が指定されていれば、`https://media.example.com:8443` のように末尾まで入力します。この値は例なので、実際に案内されたURLへ置き換えてください。

## 2. 開き方を選ぶ

### PCのブラウザーで使う

1. 管理者から受け取ったURLを開きます。
2. 証明書の警告が出ないことを確認します。警告が出た場合は進まず、管理者にURLと証明書を確認してもらいます。
3. Mireaのログイン画面が表示されたら接続成功です。

ブラウザーのタブでそのまま使えます。インストールは必須ではありません。

### ブラウザー版をアプリとして使う（PWA）

1. 対応ブラウザーでMireaのHTTPS URLを開きます。
2. ログイン画面、または「設定」→「アプリと更新」の案内を確認します。
3. 「Mireaをインストール」が表示されれば選択し、ブラウザーの確認に従います。
4. ボタンがなければブラウザーのメニューを確認します。Chrome・Edgeではアプリのインストール、iPhone・iPadのSafariでは共有メニューの「ホーム画面に追加」が入口です。表示条件や名称はブラウザーで異なります。
5. 追加されたアイコンから開ければ完了です。

インストールだけでは作品本体は保存されません。通信なしで使いたい作品は[ダウンロード](downloads.md)してください。PWAとAPK版の端末内データが共有されるとは限りません。

### Androidアプリで使う

1. 利用する配布元の署名済みAPKを入手します。Mireaの「設定」→「アプリと更新」にも導線があります。
2. Androidの確認画面に従ってインストールします。
3. Mireaを開き、接続先に案内されたHTTPS URLを入力します。
4. ログイン画面が表示されたら接続成功です。

Android 10以降が対象です。Android System WebViewも更新してください。OSがインストールを拒否した場合に保護機能を無効化して進める手順ではありません。配布元へ確認してください。[アプリ更新の案内](../android-updates.md)

## 3. ログインする

アカウントがあれば、メールアドレスとパスワードでログインします。新規登録を許可しているサーバーでは、登録画面から表示名・メールアドレス・パスワードを設定できます。登録できない場合は管理者へ依頼してください。パスワードは12〜128文字です。

「ログイン状態を保持する」は、自分専用の端末で利用します。保持したログインは最長30日で、開くたびに期限が延びるわけではありません。共用端末では保持を外し、利用後にログアウトします。

ログインするとライブラリが表示されます。新規設置した管理者は[導入手順](../install/choose.md)の初回ログインへ進んでください。初期管理者を一般利用者同士で共用しないでください。

## 4. 本棚を選ぶ

左側のメニューから本棚を選びます。狭い画面では左上のメニューボタンで開きます。スワイプ操作を覚える必要はありません。

| 名前 | 何に使うか | 例 |
| --- | --- | --- |
| 本棚 | 作品の保存先と共有範囲 | 自分の本、家族の動画 |
| シリーズ | 一つの本棚内で作品を階層と順番でまとめる | 作品名 → シーズン1 → 各話 |
| プレイリスト | 好きな作品を自分用の順番で集める | 通勤用の音楽、あとで見る動画 |

「アセット」は登録された一つの作品です。PDF一つ、動画一本、音楽一曲、まとめて登録した画像本一冊などを指します。

共有された本棚が見えない場合は接続先とアカウントを確認し、本棚の所有者に共有設定を確認してもらいます。新規登録しただけでは、他の人の本棚に参加しません。

## 5. 最初の作品を追加する

閲覧権限だけでは追加できません。自分で本棚を作成するか、本棚の所有者に編集権限を依頼します。

1. 本棚がなければ、本棚欄の「＋」または空の一覧の「本棚を作成」を選びます。
2. 名前を入力し、「本棚を作成」を選びます。
3. 「コンテンツを追加」を開き、追加先の本棚を確認します。
4. 初回は小さなPDF・動画・音声ファイルを一つ選びます。
5. 選んだ作品と追加先を確認します。Mirea 1.0.0では「追加内容を確認」→「確認した内容でアップロード」と進みます。
6. 「転送状況」で送信完了を確認します。表紙や再生用データの準備はその後も続きます。
7. 一覧に戻り、開ける状態になった作品を選びます。

画像を一冊にする場合やフォルダの取り込みは、[作品を追加する](uploads.md)を参照してください。

## 6. 開いて、次回は続きから使う

サムネイルやタイトルを選ぶと、本はリーダー、動画・音楽はプレイヤーで開きます。明示的に動画・音楽を開く操作では再生開始を試みます。ブラウザーが自動再生を制限した場合は再生ボタンを押します。

位置は作品ごとに保存します。別端末へ移る前に通信できる状態で少し待つと同期できます。通信がない間の位置は再接続後に送ります。[読む・見る・聴く](playback.md)

外出前には必要な作品を[保存](downloads.md)し、保存済みの表示と実際に開けることを確認してください。
