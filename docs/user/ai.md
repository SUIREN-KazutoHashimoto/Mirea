# タグと内容から作品を探す

Mirea 2.0.0beta向けの操作説明です。旧版に画面がない場合は、[対象版](../status.md)を確認してください。モデルの準備は[管理者の手順](../operations/ai.md)で行います。

AIの解析を待っている間も、いつもの閲覧・再生・アップロードを使えます。手動タグとタイトルの検索は、AIのモデルがなくても利用できます。

## タグを付ける

1. PCでは作品を右クリック、タッチ端末では長押しして「プロパティ」を開きます。
2. 「タグ・内容」を選びます。
3. 「共有タグ」または「自分だけのタグ」に、改行で区切って入力し、保存します。

共有タグは本棚の所有者・編集者が変更できます。個人タグは本人だけのもので、ほかの利用者には表示しません。

自動タグには誤りが含まれることがあります。「自動タグを採用して保持」で確定すると、再解析後も残せます。不要な自動タグを外すと、同じタグの再提案も非表示になります。「非表示にしたタグ」から再び表示できます。

一覧の「タグを編集」は、その一覧に含まれる作品をまとめて変更します。保存先、追加か解除か、対象件数を確認してから実行します。「タグを整理」では既存タグを検索し、名前の変更や統合ができます。共有タグの整理は選んだ本棚だけが対象です。

## 内容を探す

1. コンテンツ一覧の「内容から探す」を選びます。
2. 覚えている本文・セリフ・発話・章の言葉を入力します。
3. 必要ならタグと「すべてを含む／いずれかを含む」を指定し、検索します。

現在の本棚、シリーズ、プレイリスト、種類が検索の範囲です。まだ解析されていない作品も、タイトルや手動タグで探せます。

「内容が近い作品も探す」は、ローカルで意味を比較します。準備に時間がかかる場合は先に言葉の一致を表示します。「内容の近い候補も表示」が出たら、選んで結果を切り替えます。表示中の作品が勝手に並び替わることはありません。

本文や章名の抜粋は初期状態では表示しません。内容を見たい場合だけチェックを入れます。作品名を選ぶと通常の続き位置、ページ番号や時刻を選ぶと該当箇所を開きます。検索で指定した時刻は、次の作品の連続再生へ持ち越しません。

よく使う条件は名前を付けて保存できます。保存済みの条件を選ぶと同じ一覧で開き、現在の条件による更新や削除もできます。関連作品は「タグ・内容」から、共通タグを根拠に確認できます。

## 認識した文字を読む・訂正する

「タグ・内容」→「認識した内容」で、本文・セリフ・文字起こしなどを選びます。長い作品の結果は分割して取得するため、「続きの結果を表示」で進みます。

PDF・画像本のリーダーでは「文」のボタンを選ぶと、認識領域をページに重ねて表示します。領域を選ぶと文字の確認・コピーができます。表示を閉じると通常のページ操作に戻ります。

所有者・編集者は「訂正」で文字、区間名、時刻を直したり、その箇所を非表示にできます。「非表示にした箇所を確認」から表示に戻せます。音楽・動画の区間では分割位置を指定した分割や、次の区間との結合もできます。

訂正はAIが作った原情報とは別に保存します。再解析で対応する領域が変わった場合、別の箇所へ勝手に適用しません。「対応する箇所が変わった訂正」に保持し、内容を確認してから現在の箇所を訂正できます。不要になった旧訂正は確認済みにできます。過去の訂正記録は残ります。

## 曲の構成・動画の章を使う

音楽・動画プレイヤーの区間ボタンから、解析された構成や章を開きます。Web/PWAでは重ね表示と固定表示を選べます。Androidのネイティブプレイヤーではメニューから開きます。

区間を選ぶとその時刻へ移動します。A–Bリピートを選ぶと、選択時の開始・終了を繰り返します。その間は通常の末尾の連続再生を保留し、解除すると元の再生順へ戻ります。作品を変えると区間リピートは解除します。解析情報の更新だけで音量や再生位置を初期化しません。

シークバーにも区間の境界を表示します。「次のサビへ」は現在位置より後のサビへ移動し、末尾なら最初のサビに戻ります。Web/PWAでは「区間の開始・終了を調整」、Androidでは区間を選んで「開始・終了を調整してリピート」から、秒単位で範囲を微調整できます。

構成や章は解析による推定です。ライブ、メドレー、長い間奏などでは境界や名称を確認・訂正してください。

## 解析を依頼・確認する

単体は「タグ・内容」の「解析・再解析を依頼」、一覧は「解析を依頼」を使います。本棚所有者は、本棚メニューの「本棚の解析」で新しい作品の自動解析や既存分の解析も設定できます。

「内容から探す」→「解析の状況」で、自分の依頼を確認できます。待機、解析中、一時停止、失敗・一部未解析、完了を切り替え、停止・再開・未解析分の再試行ができます。本棚を選んで開くとその本棚に絞ります。プライベート本棚には通常と同じ追加認証が必要です。

一括依頼は、先に対象を保存し、少しずつ個別の解析待ちへ登録します。登録状況と実際の解析状況は別です。サーバー再起動後も、保存済みのページ・時間区間を使って続きから再開します。完了予想は処理済み部分からの目安で、内容が変わると変動します。

## 外出先で使う・書き出す

作品を端末に保存すると、解析情報と曲の区間も追加で保存します。保存済みの内容は、既存の端末保存と同じく、サーバー・利用者ごとに暗号化して最長7日間利用できます。

元の作品を閲覧できる範囲だけが対象です。別のアカウント、期限切れ、時計の巻き戻し、サーバーで確認できた権限拒否を、古いキャッシュで回避しません。プライベート本棚は追加認証を必要とします。

接続中は「解析情報を書き出す」で、ページ分割された全結果と現在の訂正をJSONにできます。作品名や認識本文を含むため、自分の保存先・共有先を確認してください。サーバー内部のパス、鍵、認証情報は含めません。

## 訂正を以前の状態へ戻す

「認識した内容」→「訂正の履歴」で、日時と版を選び、訂正内容を確認して「この訂正に戻す」を押します。戻した操作も新しい履歴に残ります。「現在の解析結果（訂正なし）」を選ぶと、現在の手動訂正を外して認識した状態へ戻せます。元のアセットは変更しません。
