# 共有とプライバシー、アカウントを管理する

作品を誰と共有するかは本棚で決めます。プレイリストや端末保存を作っても、元の本棚の権限を越えて作品を見せることはできません。

> 対象は Mirea `1.0.0` です。[文書一覧](../README.md)

## 本棚を共有する

1. 共有相手に、同じサーバーでアカウントを作成してもらいます。
2. 本棚名の横の「⋯」→「共有設定」を開きます。
3. 登録済みのメールアドレスで相手を追加します。
4. 閲覧だけなら「閲覧者」、作品の追加・編集・削除も任せるなら「編集者」を選びます。
5. 相手に本棚が表示され、作品を開けることを確認してもらいます。

共有設定を変えられるのは本棚の所有者です。本棚ごとに権限を設定するため、ある本棚の編集者でも、別の本棚を自動で見られるわけではありません。

共有を解除すると、その後のアクセスは拒否します。ただし、相手の端末が通信していない間に遠隔で即時回収する仕組みではありません。事前に許可した端末保存は、再接続による失効確認または期限まで利用できる場合があります。

## プライベート本棚にする

1. 自分が所有する本棚の「⋯」を開きます。
2. 「プライベート本棚（すべてのコンテンツに表示しない）」をオンにします。
3. その本棚を開き、本人確認の案内に従います。

プライベート本棚の作品は「すべてのコンテンツ」と通常の閲覧履歴に表示しません。設定は本棚単位です。共有を取り消す機能ではないので、メンバーも見直したい場合は共有設定で変更してください。

### Web/PWAで開く

本人のMireaアカウントのパスワードを入力して「開く」を選びます。端末のPINやOSのパスワードではありません。

### Androidアプリで開く

最初は通信できる状態でMireaのパスワードを入力します。対応端末では生体認証用の登録を行い、次回以降は自動で生体認証を要求します。認証を閉じたり失敗したりした場合は、Mireaのパスワードで開けます。

端末の生体情報や鍵が変更された場合は、パスワードで登録し直す必要があります。生体認証がない端末でもパスワードによる利用はできます。

通信できない場所で初めて本人確認の準備をすることはできません。外出前にその端末で一度開き、必要な作品のダウンロードも済ませてください。本人確認に成功しても、作品の保存期限そのものが延長されるわけではありません。

## 閲覧履歴を整理する

「閲覧履歴」は本人が最後に閲覧した順の作品一覧です。シリーズにまとめず、作品単位で表示します。

- 一件を隠す場合は、その作品のメニューから「閲覧履歴から非表示」を選びます。
- 全件を隠す場合は「閲覧履歴をすべて非表示」を選びます。
- 再び開いた作品は履歴に戻ります。

これは履歴画面の表示を整理する操作です。作品・続き位置・サーバー上の詳細な閲覧記録は削除しません。端末のダウンロード解除とも別です。

## どのような記録が保存されるか

Mireaは、作品を開いたこと、ページや表示範囲、再生区間、シーク・一時停止などを記録します。通信できない間は端末側に保留し、接続後に送ります。続き位置は再開用の情報として別に管理します。

| 情報 | 利用者ができること | 他の人との関係 |
| --- | --- | --- |
| 自分の履歴・続き位置 | 閲覧・再開・履歴表示の整理 | 通常の本棚共有画面から他人の個別履歴は見えない |
| 自分の詳細記録 | 「設定」→「記録と診断」から書き出す | 書き出した内容は本人向け。公開投稿用の診断ではない |
| 本棚・サーバーの匿名統計 | 権限のある管理者が集計を見る | 5人以上などの集計条件があり、当日分を除く |
| 再生頻度のグラフ | シーク中に見る | 匿名集計が不足する場合は、自分の傾向と明示する |

詳細記録は、通常はサーバーに期限を設けず保持します。管理者は新しい記録の収集を止める設定を持っています。時間は端末からの推定で、集中して見ていたことや読了を証明する値ではありません。

**サーバーのDBや復号したバックアップを直接読める運営者から、個別記録を隔離する仕組みではありません。** プライベート本棚や端末の暗号化保存も、サーバー運営者へ原本を隠す仕組みではありません。信頼できるサーバーを利用してください。

## エラーを管理者へ送る

1. エラーのある画面で「エラーの詳細を見る」を開くか、「設定」→「記録と診断」→「エラーの詳細を開く」を選びます。
2. マスクされた診断情報を確認します。
3. コピーして管理者へ伝えるか、画面にあるサーバーへ送る操作を選びます。
4. 「何をしようとしたか」「どの操作で起きたか」「Web/PWA/Androidのどれか」も添えます。

送信用診断には、許可したエラーコード・発生時刻・版・ソース位置などを含めます。作品名、メール、認証情報、保存先、例外の原文などの不要な情報は送信用の項目に含めません。送信は本人が操作したときに行います。サーバー管理者は届いた報告を送信単位で確認・コピーできます。

詳細な閲覧記録の書き出しや、画面全体のスクリーンショットは別物です。こちらには作品名などが写る場合があります。診断の代わりにそのまま公開しないでください。

## 名前・メールアドレス・パスワードを変更する

1. 「設定」→「アカウント」を開きます。
2. 変更する表示名・メールアドレスを入力します。パスワードを変える場合は新しいパスワードも入力します。
3. 現在のパスワードを入力し、「変更を保存」を選びます。
4. 他の端末では、新しい情報でログインし直します。

変更すると他の端末の古いログインは失効します。現在の端末はログイン情報を更新します。通常ユーザーもこの画面で自分のユーザーUUIDを確認できます。サポートで指定された場合以外に公開する必要はありません。

初期管理者の警告がある場合は、メールアドレスとパスワードの両方を変更してください。完了するまで管理操作を制限します。

パスワードを忘れた場合は、サーバーの運営者へ連絡してください。メールアドレスを登録しただけで、自動のメール確認やメールによるパスワード再設定が利用できるわけではありません。

## ログアウトとアカウント削除の違い

ログアウトはこのログインを終了する操作です。サーバーのアカウントや作品を削除しません。ただし、端末保存の閲覧許可を無効にするため、再ログイン・再認可が必要になります。

「設定」→「アカウントの削除」は退会です。アカウント、本人の詳細記録・続き位置・ダウンロード登録と、この端末の保存データを削除します。共有本棚の作品は残り、アップロード者との関連を外します。

所有している本棚に作品や他のメンバーがいる場合は、先に所有権を引き継ぎます。自分だけの本棚なら、必要な作品を退避して空にする方法もあります。最後の有効なサーバー管理者は、引き継ぎなしでは削除できません。

退会の画面で対象を確認し、メールアドレス・現在のパスワード・確認チェックを入力してから確定します。元に戻せません。他端末の保存許可は利用できなくなりますが、暗号化データの物理的な削除は各端末で行います。
