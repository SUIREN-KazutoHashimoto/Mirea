# 本を読む、動画を見る、音楽を聴く

一覧で作品を選ぶと、対応するリーダーまたはプレイヤーが開きます。前回の位置があれば、そこから再開します。シリーズやプレイリストから開くと、その中の前後移動も利用できます。

> 対象は Mirea `1.0.0` です。[文書一覧](../README.md)

## 最初に開く

1. サムネイルまたはタイトルを選びます。
2. 本はページが表示されるまで待ちます。動画・音楽は再生開始を試みます。
3. ブラウザーが自動再生を許可しなかった場合は再生ボタンを押します。
4. 再生位置を変える場合はシークバーをクリック・ドラッグします。本はページ番号でも移動できます。

前回最後まで再生した作品は、次回は先頭から始める場合があります。「最初から」を選べば、自分で先頭へ戻せます。プレビューの視聴は本編の続き位置を変えません。

## メニューを表示・固定する

Web/PWAの上部メニューは、作品に重ねて表示します。隠れている場合は「•••」の操作メニューボタンや作品上の操作で表示します。

「操作メニューを固定」をオンにすると、メニューのための領域を確保します。本や動画にメニューがかぶらない状態で常時操作したいときに使います。固定を解除すると、作品の表示領域を広く使えます。

全画面ボタンはブラウザー・端末の対応範囲で働きます。Androidの動画プレイヤーでは画面方向の切り替えも利用できます。OSが対応しない機能は利用できません。

## 本の操作

| したいこと | 操作 |
| --- | --- |
| 前後のページへ進む | ページ端のタップ、左右スワイプ、前後ボタン |
| 指定ページへ移る | ページ番号を入力、進行度のバーを操作、ページ一覧から選ぶ |
| ページを大きくする | 表示倍率を選ぶ |
| 全体を見る | 「ページ全体」を選ぶ |
| 横幅に合わせる | PDF・画像本の「画面の幅に合わせる」を選ぶ |
| 漫画などのページ方向を変える | 「左開き」「右開き」を選ぶ |
| EPUBの章へ移る | 目次を開いて章を選ぶ |
| EPUBの文字サイズを変える | EPUBの表示設定を使う |

ページ移動用の矢印キーは開き方向に従います。入力欄を操作中は、入力を優先するためページ移動が働かない場合があります。

画像本はページを先に読み込みますが、容量とメモリの上限内で扱います。PDFは必要な範囲や近くのページを準備します。大きな本すべてを必ずメモリへ展開しておく方式ではありません。遠くのページへ飛んだときや通信が遅い場合には読み込みが発生します。

EPUBはDRMのないリフロー型EPUB 2/3が対象です。固定レイアウトや、販売店のDRM付き書籍は対象外です。

## 動画と音楽の操作

アイコンには操作名があります。PCではマウスを重ねた表示や、キーボード・スクリーンリーダーで確認できます。

| 操作 | 意味 |
| --- | --- |
| 再生／一時停止 | 現在の作品を止める・再開する |
| 10秒戻る／進む | 再生時刻を移動する |
| 前の作品／次の作品 | 開いているシリーズ・プレイリスト内で移動する |
| 再生速度 | 速度を変更する。長押しの一時的な2倍速とは別 |
| リピート | なし、現在の作品だけ、シリーズ／リストを繰り返す |
| シャッフル | シリーズ／リスト内の移動順をランダムにする |
| イコライザー | 低音から高音までの音のバランスを調整する |
| 画質 | 自動、高画質優先、データセーバー、生成済みの固定画質から選ぶ |

前後移動やシリーズリピート・シャッフルは、移動先のある再生単位で利用できます。単独作品しかない場合に別の本棚へ勝手に移ることはありません。

Web/PWAの音量・消音・速度は、この端末の同じアカウント・サーバー用に保持します。サイトデータを消した場合や別のブラウザーでは初期状態になります。

### 動画の便利な操作

- 動画を長押ししている間は一時的に2倍速にし、指を離すと元の速度に戻します。
- 再生頻度のグラフはシーク操作中に表示します。十分な匿名集計がなければ「自分の再生傾向」を使います。データがなければグラフは出ません。
- チャプター・字幕が用意されている作品では、それらの操作が使えます。字幕がない動画に自動で字幕を付ける機能ではありません。
- 原本再生中は、変換済みデータ用の画質選択が使えないことがあります。

### イコライザーを調整する

1. イコライザーのアイコンを開きます。
2. 「有効にする」をオンにします。
3. まず「フラット」「低音を強調」「声を聴きやすく」「高音を明瞭に」から試します。
4. 細かく調整したい場合は、横軸の周波数に沿った15帯域を動かします。狭い画面では横にスクロールできます。
5. 元に戻す場合は「フラットに戻す」か、機能をオフにします。

動画と音楽で使い、設定は端末側で保持します。Webの音声処理を開始できない場合は、再生ボタンを押してから再度有効にしてください。ヘッドホンやOS側のイコライザーも有効だと効果が重なるため、思った音にならない場合は両方の設定を確認します。

## 連続再生・連続閲覧

シリーズやプレイリストから開くと、現在の並びを使って前後に移動できます。音楽・動画の連続再生では次の候補を準備し、同じプレイヤーで移動します。通信状況や形式によって、完全に無音の間隔なく切り替わることまでは保証しません。

音楽・動画は、自動で次へ進む場合も、プレイヤーの「前の作品」「次の作品」や作品選択で切り替える場合も、移動先の先頭から再生します。ライブラリの一覧から作品を直接開く場合は、保存済みの続き位置から再開します。

本は最終ページから次へ進む操作で次の作品へ移れます。最終ページを表示しただけで自動的に読書を進めることはありません。子シリーズの中へ自動で降りて全階層を再生する動作ではありません。

移動直前にも権限と作品の状態を確認します。削除・共有解除された作品や、保存が必要なのに未取得の作品は開けません。リストに登録されているだけでは、再生用データが端末に保存されたことにはなりません。

次の作品を準備している間も「自動移動を停止」で今回の移動を取り消せます。準備に失敗した場合は現在の作品を残し、再度「次の作品」で試せます。

## ライブラリへ戻って再生を続ける

音楽・動画のプレイヤーを閉じてライブラリへ戻ると、再生を続けるための小さな操作表示を利用できます。そこからプレイヤーへ戻る、一時停止する、表示を最小化する操作ができます。停止したいときは再生操作から明示的に停止・一時停止します。

動画のPiPは小さな別画面で再生を続ける機能です。Androidと対応ブラウザーで利用します。利用できないブラウザーでは通常の小型表示やバックグラウンド再生を使います。

対応ブラウザーで動画を連続再生する場合は、PiPの小窓を保ったまま次の作品へ移ります。通常表示に戻ると、その時点で再生中の作品を操作できます。

| 利用環境 | ホーム画面や別アプリへ移ったとき |
| --- | --- |
| Android APK | 独立した再生サービスで継続し、通知・ロック画面の操作を利用する。動画のPiPには端末の許可が必要な場合がある |
| Web/PWA | タブ・ウィンドウとブラウザーの動作に依存する。タブ終了、OSによる停止後の継続は保証できない |

ブラウザーやアプリを終了して次回起動した場合は、前回の作品を再開できる停止状態の表示を利用します。起動しただけで音を出す扱いにはしません。端末側で再生サービスが動作している場合は、その現在の状態を表示します。

## PCのキーボード操作

プレイヤー内にフォーカスがあるときの操作です。入力欄や別のメニューを開いている場合は、その操作を優先します。

| キー | 動画・音楽の操作 |
| --- | --- |
| Space / K | 再生・一時停止 |
| J / L | 10秒戻る・進む |
| ← / → | 5秒戻る・進む |
| ↑ / ↓ | 音量変更。シークバーにフォーカス中は再生位置の変更 |
| 0〜9 | 全体の0〜90%位置へ移動 |
| Home / End | 先頭・末尾へ移動 |
| `<` / `>` | 再生速度を下げる・上げる |
| Shift+P / Shift+N | 前・次の作品 |
| M | 消音切り替え |
| F | 全画面切り替え |
| I | 小型表示へ移る |
| C | 字幕切り替え（字幕がある場合） |
| Ctrl+← / Ctrl+→ | 前・次のチャプター |
| , / . | 一時停止中のフレーム移動 |

## 途切れや位置ずれが気になるとき

通信が不安定な場所では、事前に[必要な作品を保存](downloads.md)すると通信への依存を減らせます。接続が戻るたびに手動でモードを切り替える必要はありません。

別端末の位置と競合した場合に、古い記録で新しい位置を黙って巻き戻すことは避けます。ただし、二つの端末で同じ作品を同時に進めると、自分が意図した一つの位置に自動で決められない場合があります。端末を切り替える前に一時停止し、同期後に次の端末で開く使い方が確実です。

再現する問題は[困ったとき](help.md)から、安全な診断情報と操作手順をまとめて管理者へ伝えられます。[再生設計](../design/playback.md)には内部の状態と制約を記載します。
