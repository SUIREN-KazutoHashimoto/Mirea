# 自分のアセットの処理状況を確認する

Mirea 2.2.0beta以降では、メニューの「自分のジョブ」を開くと、所有するアセットのアップロード後処理・表紙生成・AI解析をまとめて確認できます。PC、PWA、Androidアプリで同じ入口を使えます。

1. 「現在のジョブ」で、実行中・待機中・一時停止を確認します。
2. 作品名・種類・ジョブIDで検索し、必要なら状態で絞ります。
3. 行を選ぶと、受付日時・経過時間・終了予想や失敗理由が開きます。AI解析はここから一時停止・再開・未解析分の再試行ができます。
4. 完了・失敗・中止は「履歴」から確認します。100件ごとにページを切り替えられます。

自分で依頼したものだけでなく、自動解析や別の端末・編集者から依頼された処理も対象です。本棚所有者は本棚全体、追加した本人は現在も閲覧権限がある自分のアセットを確認できます。権限を失った本棚の情報は表示しません。

プライベート本棚は、先に本棚を開いて追加認証してください。未認証の内容は「自分のジョブ」から取得しません。管理者の全体一覧では件数と処理状況を確認できますが、作品名は伏せます。

## AI解析だけを確認する

コンテンツ一覧の「解析の状況」では、実行・待機・一時停止・要確認・完了の件数と、解析種類ごとの進捗を表示します。「一括依頼の登録状況」は解析完了の件数とは別です。大量依頼は対象を保存したあと、少しずつ解析待ちへ登録します。画面を閉じても登録済みの依頼はサーバー側で続きます。

「解析を依頼」での一覧登録は1000件ずつに分けます。途中で通信が切れた場合は、同じ画面から再試行してください。登録済みの部分を重複作成しません。確認画面の対象件数を見てから実行してください。

## 管理者の表示

「サーバー管理」→「ジョブ管理」は、AI解析を含むサーバー全体の状況を表示します。サーバー管理権限は本棚の所有権とは別です。他人のアセットは作品名・本棚名と自由形式のエラー文を伏せます。所有するアセットの名前は表示しますが、プライベート本棚の追加認証は必要です。名前での検索も同じ権限を使います。
