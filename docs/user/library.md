# 本棚と作品を整理する

本棚は共有範囲、シリーズは作品のまとまり、プレイリストは自分用の選曲・選書に使います。フォルダ管理から移行する場合も、先に使い分けを決めると整理しやすくなります。

> 対象は Mirea `1.0.0` です。[文書一覧](../README.md)

## 一覧から作品を探す

1. 左メニューで「すべてのコンテンツ」、本棚、シリーズ、プレイリストのいずれかを開きます。
2. 「タイトルで検索」に文字を入れるか、「本」「動画」「音声」で種類を絞ります。
3. 必要に応じて表示形式・表示情報・並び順を変えます。

| 設定 | 内容 | 使い分け |
| --- | --- | --- |
| 表示形式 | 2列、3列、5列、リスト | 表紙を見たいなら列表示、大量のタイトルを探すならリスト |
| 表示情報 | 詳細、サムネイル＋タイトル | 容量や続き位置も見たいなら詳細 |
| 並び順 | 追加日時、タイトル、サイズ、続きから、設定した順 | 一覧上の見え方を変更 |

一覧のソートと、シリーズ・プレイリストに保存する再生順は別です。再生順を変える場合はシリーズやプレイリストを編集します。閲覧履歴は最後に閲覧した順です。

一覧は定期的に更新し、同じ内容なら表示を維持します。すぐ確認したい場合は更新アイコンを使います。タッチ操作では一覧の上端で下に引く操作でも更新できます。

## 作品メニューを開く

- PCのWeb/PWAでは右クリック。キーボードでは作品へフォーカスして `Shift+F10`。
- タッチ画面では作品を長押し。
- 普通のクリック・タップは作品を開く操作です。

Web/PWAは「名前を変更」「プレイリストに追加」「暗号化ダウンロード」「削除」「プロパティ」の順です。アプリの長押しメニューには保存状態と「詳細を表示」があります。権限や作品の準備状況によって利用できない操作は無効になります。

「プロパティ」／「詳細を表示」で、本棚、種類、サイズ、ページ数、続き位置、端末保存状態を確認できます。

## 本棚を作成する

本棚欄の「＋」から名前と任意の説明を入力し、「本棚を作成」を選びます。同じ名前の本棚も作れますが、共有相手が見分けられる名前が便利です。

本棚名の横の「⋯」で本棚メニューを開きます。名前変更・共有・プライベート設定・本棚の削除は所有者が操作します。

| 本棚での役割 | 閲覧 | 作品の追加・編集・削除 | 共有・所有権の管理 |
| --- | --- | --- | --- |
| 所有者 | 可 | 可 | 可 |
| 編集者 | 可 | 可 | 不可 |
| 閲覧者 | 可 | 不可 | 不可 |

サーバー管理者は本棚の役割とは別です。[共有とプライバシー](privacy.md)も確認してください。

## シリーズを作る

1. 「シリーズを追加」を開きます。
2. 本棚とシリーズ名を指定します。
3. 入れ子にしたい場合は「親シリーズ」を選びます。最上位なら「なし（最上位）」のままにします。
4. 「シリーズを作成」を選び、編集画面で作品を追加して「シリーズを保存」を選びます。

シリーズを開くと直下の作品と子シリーズを表示します。「一覧へ戻る」「親シリーズへ」で一つ上へ戻れます。Androidの戻る操作でもシリーズの外へ戻ります。

同じ本棚内で最大16階層です。シリーズ名と作品タイトルは、それぞれ同じ階層で重複できません。別階層なら同名を使えます。旧データに重複がある場合は手動で整理します。自動統合や上書きはしません。

## シリーズへまとめて作品を追加する

1. シリーズを開き、「シリーズを編集」を選びます。
2. 「追加する作品を検索」でタイトルや所属シリーズを検索します。
3. 候補を複数選択します。「検索結果をすべて選択」も使えます。
4. 「選択した作品をまとめて追加」を選びます。
5. 並び順と巻・話ラベルを確認して「シリーズを保存」を選びます。

Mirea 1.0.0では、候補は200件ずつ、登録済みの並びは100件ずつ追加表示します。同じ本棚の別シリーズから選ぶと、保存時にその作品を移動します。複製は作りません。作品は一つのシリーズにだけ所属できます。

Mirea 1.0.0では1シリーズ100,000作品まで扱えます。一度のファイル選択・アップロードの上限1,000件とは別です。登録上限は、すべての端末でその件数を快適に編集できる保証ではありません。検索で範囲を絞って操作してください。

## 再生順を決める

| シリーズの設定 | 動作 |
| --- | --- |
| 名前の昇順 | 数字を考慮した名前順。作品の追加・名前変更時も順番を合わせる |
| 手動で指定 | 上下ボタンで自分の順番に並べる |

「第1巻」「特典」「外伝」などの巻・話ラベルは表示用で、ラベルだけで順番が決まるわけではありません。子シリーズ内の順番は子シリーズ側で管理します。

別の画面で同時に編集されると保存時に競合を知らせます。変更内容を控え、「保存せず最新の内容を読み直す」で最新状態にしてから編集し直してください。

## プレイリストを作る

1. 左メニューの「プレイリスト」→「リストを作成」を選びます。
2. 名前を入力して作品を検索します。
3. 音楽・動画・本のいずれかを一つ選び、同じ種類の作品を追加します。
4. 順番を確認して「作成」を選びます。

本人専用で、本棚をまたいで作れます。同じ作品を複数リストに追加でき、元の本棚・シリーズは変わりません。音楽・動画・本を一つのリストへ混在させることはできません。PDF・EPUB・画像本は「本」として扱います。

Mirea 1.0.0では検索結果のまとめ追加、名前の昇降順、逆順、位置番号への移動を使えます。編集後は「保存」を選びます。1人200リスト、1リスト1,000作品までです。

音楽・動画のリストには連続再生の入口があります。リストから開いたプレイヤーの前後移動も、そのリストの順番を使います。権限を失った作品をリストに入れていても閲覧権限は得られません。

## サムネイルを変更する

| 範囲 | 操作する場所 |
| --- | --- |
| 一つの作品 | 「プロパティ」／「詳細を表示」→「サムネイルを変更」 |
| 一覧の複数作品 | 一覧の「サムネイル変更」で対象を選ぶ |
| シリーズ全体 | シリーズ内の「サムネイルを変更」。子シリーズも含む対象を確認する |

JPEG・PNG・WebPの静止画像、5 MiB以下を使います。画像書籍の1枚100 MiBという上限とは別です。縦横比を保って長辺1,024px以下のWebPへ変換し、アップロードしたカスタム画像の原本は別に保持します。

ジョブの再生成でもカスタム画像を優先します。「自動サムネイルに戻す」を選ぶと自動生成画像に戻せます。作品の原本や動画プレビューは表紙画像で上書きしません。

## 削除と解除を区別する

| 操作 | 何が変わるか |
| --- | --- |
| 端末のダウンロードを解除 | この端末の保存データを削除。サーバーの作品は残る |
| シリーズから「外す」 | 所属を解除。作品は同じ本棚に残る |
| プレイリストから外す／リストだけ削除 | リスト上の参照を解除。作品は残る |
| シリーズだけ削除 | そのシリーズを削除し、子シリーズと作品は残す |
| シリーズ削除で「配下のシリーズ・アセット・原本もすべて削除」を選ぶ | 確認画面に示された範囲を削除。共有相手も利用できなくなる |
| 作品をサーバーから削除 | 原本・派生データを含む作品を削除 |
| 本棚を削除 | 中の全作品も削除。名前・現在のパスワード・確認チェックが必要 |
| 閲覧履歴から非表示 | 履歴画面から隠す。作品・続き位置・詳細な記録は残る |

削除対象の件数とチェックを確認してから確定してください。配下も削除する選択は元に戻せません。残したい作品は先に移動するか、管理者へバックアップを依頼します。

削除される作品は現在の所属で決まります。別のシリーズへ移動済みの作品は、元のシリーズを削除しても残ります。確認後に他の操作で対象が変わった場合は、削除を進めず、最新の内容を確認し直してください。
