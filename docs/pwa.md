# ブラウザー版をアプリとして使う（PWA）

> このページは旧リンクからの案内です。Mirea `1.0.0`の手順は、以下の利用者ガイドにまとめています。公開版ごとの変更は[リリース履歴](../RELEASE.md)を参照してください。

PWAはMireaを独立したウィンドウで起動するためのブラウザー機能です。Android APKとは別のアプリで、インストールだけで作品の本体は保存されません。

1. 管理者から案内された、証明書の警告が出ないHTTPS URLを開きます。
2. ログイン画面または設定の「アプリと更新」でインストールの案内を確認します。
3. ボタンがない場合はブラウザーのインストールメニューを使います。iPhone・iPadではSafariの共有メニューからホーム画面に追加する方法があります。表示名や対応範囲はブラウザーで異なります。
4. 起動用アイコンができたら、同じサーバーにログインします。

ブラウザーのプロファイル、URL、APKを変えると保存領域が別になります。タブの終了やOSの停止後まで再生・転送が続くとは限りません。
