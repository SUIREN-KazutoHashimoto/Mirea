# ブラウザー版をアプリとしてインストール（PWA）

PC／AndroidのChrome・EdgeでMireaを開き、ログイン画面または「設定 → ブラウザーアプリ（PWA）」の「Mireaをインストール」を押します。ボタンはブラウザーからインストール可能と通知されたときに表示します。表示されない場合はブラウザーのアドレスバー／メニューのインストール項目を確認してください。iPhone／iPadではSafariの共有メニュー →「ホーム画面に追加」を使います。対応・表示名はブラウザーによって異なります。

- 信頼されたHTTPSが必要です。LANのAD CSルートCAは使用端末で信頼登録し、サーバー証明書のSANに合う、警告の出ないURLで開きます。警告を通過するだけでは利用できません。
- インストール後はホーム画面／デスクトップから独立ウィンドウで起動できます。APK版とは別で、保存データが共有されるとは限りません。サーバーURLを変えると別のサイトデータになります。
- インストールだけでメディア本体を取得しません。作品は従来の暗号化ダウンロードから保存します。視聴期限は最後の接続から7日間、再接続時の権限確認・同期も従来どおりです。
- Service Workerは既存のものを共用し、固定の画面・アイコンだけをキャッシュします。API・認証情報・メディアの平文を新たにキャッシュしません。サーバー更新時も勝手に画面を再読み込みしません。
- PWAのインストールはOSのネイティブサービスではありません。ブラウザーの省電力・終了・容量管理によってバックグラウンド再生／転送・保存期間には制約があります。APKと同じ動作を保証しません。
- 古いMireaタブが保存領域の更新を待たせている場合は、そのタブを再読み込みしてください。待ち続けて画面が真っ白になることを防ぎ、取得済みの暗号化データ・鍵は削除しません。

参考: [MDN: インストール可能にする](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable)、[インストールの案内](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/How_to/Trigger_install_prompt)。
