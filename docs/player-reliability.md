# プレイヤーの点検と0.20.1betaの修正

動画・音楽の画面、WebのMedia Session、Android再生サービス、暗号化保存、シリーズ移動、本のページ移動を点検しました。操作や保存形式の大枠は維持します。DB schema21・既存APK署名者・保存鍵・証明書は変更しません。

## 修正した問題

- Androidで、デコーダーの通信エラー後に再生位置・長さを失い、再接続が先頭へ戻る問題。直前の位置と速度、再生／一時停止の意図を保持します。通知の再生操作からも再試行できます。
- 一時停止中の画質切替・再接続・シリーズの前後移動が、最初の自動再生指定を再利用して勝手に再開する問題。準備中の一時停止も尊重します。
- 保存済み音声・動画の起動が進行度の通信や表紙取得を待つ問題。端末の続き位置・暗号化ファイルから準備し、通信や任意情報の処理を別にします。
- 通信断直後の二重の権限更新で、有効な保存済みデータまで開けなくなる問題。接続失敗は既存の有効な閲覧許可へ戻し、認証・権限拒否には戻しません。
- オフライン再生中の同期が通信タイムアウトを繰り返し、操作や次の作品を待たせる問題。短い同期時間制限と5～60秒の再試行間隔を使用し、回線復帰で再試行できます。通信失敗で閲覧期限を延長しません。
- オンラインで開いた保存済み作品が、接続切替後にシリーズ情報を失う問題。開始時に端末のシリーズ情報も渡します。サーバーへ到達できない場合だけ保存済み情報を使い、明示的な権限拒否は迂回しません。
- Androidの旧接続・表紙／字幕／集計取得が次の再生準備を妨げる問題。処理列を分離し、終了した接続は閉じ、遅れた結果を世代で除外します。
- アプリの最小化プレイヤーの位置表示が更新されない問題。
- Webで画質を続けて変えると、読み込み途中の0秒を復元位置として保存する問題。読み込み前の位置・速度・停止状態を引き継ぎます。
- Webの更新チケット取得が通信断で失敗した後、再試行されない問題。時間をおいた再試行と回線復帰時の再試行を行い、閉じた画面へ遅れて反映しません。
- WebでPiPからプレイヤーへ戻ってもPiP表示が残る問題、SafariのPiPボタンで解除できない問題。
- 古い画面の終了処理が新しいOSメディア操作を解除する問題。表紙の遅れた取得も現在のプレイヤーだけに反映します。
- Webの音声再生が表紙の取得完了を待つ問題。表紙なしで再生を準備でき、取得後はOSメディア操作にも表紙を反映します。
- Webで連続再生をオフにすると、明示的な移動後の再生まで抑止される問題。連続移動と現在の再生状態を分けます。
- オフラインで最後まで再生した作品を開き直すと、末尾位置へ復元される問題。
- アプリ復帰時の大量の記録同期が、暗号化キャッシュを開く処理と同じ列を占有する問題。同期を別の列にし、重複要求をまとめます。最初のオフライン再生も既知の進行度リビジョンに結び付け、他端末との競合を検出します。
- 横画面の音楽プレイヤーで表紙が上部メニュー・操作欄の下へ隠れる問題、小画面・文字拡大時の補助ボタンの折り返し切れ。

## 検証範囲

実ユーザーのデータを使わず、合成動画・音声・PDF、期限と権限のテスト、AndroidのRobolectricテスト、独立したヘッドレスブラウザーで再接続・画質変更・最小化・復帰・ページ表示を確認します。PC、390px、320px、横画面を対象とします。通常のAPI・保存・暗号化・履歴の回帰検査も実行します。

Android実機固有のメーカー省電力設定、Bluetooth機器、実際の通信回線の切替、PiPのシステム動作は自動テストで完全には再現できません。実機確認は公開APKで行ってください。Codexのサーバー検証にはWinVAI01 LANを使い、TrueNASの利用者データは調査しません。

Web/PWAのバックグラウンド再生にはタブまたはPWAを開いておく必要があり、OSによるプロセス終了後の再生はできません。未保存のストリーミング作品は通信断後に未取得部分を再生できません。保存済みデータの閲覧期限は、最後に正常に権限を確認してから最大7日間のままです。
