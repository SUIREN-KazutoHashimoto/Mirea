# 設定・サーバー管理・転送状況

> このページは旧リンクからの案内です。Mirea `1.0.0`の手順は、以下の利用者ガイドにまとめています。公開版ごとの変更は[リリース履歴](../RELEASE.md)を参照してください。

個人の設定と、サーバー全体の管理は分かれています。管理者でない利用者も、自分の保存データ・アカウント・転送・診断を扱えます。

| 画面 | 主な用途 |
| --- | --- |
| 設定 → 表示 | テーマなど、この端末での表示 |
| 設定 → アカウント | 表示名・メール・パスワード・UUID |
| 設定 → 保存とオフライン | 保存済み作品、一覧・表紙の保存 |
| 設定 → アプリと更新 | APK・PWAの案内と更新 |
| 設定 → 記録と診断 | 本人の記録、マスク済みエラーの送信 |
| 転送状況 | 自分の送信・保存と、その後処理の状態 |
| サーバー管理 | 管理者向けのジョブ・設定・運用 |

ジョブ管理は「現在のジョブ」「履歴」「アセットの再生成」に分かれます。実行待ちと処理中を調べるときは現在のジョブを開き、検索・状態で絞ります。表示件数と取得範囲の説明も確認してください。CPUの使用率だけでは、どのジョブが動いているかは判断できません。

正常な作品まで作り直さず、未完了の作品だけを修復する操作もあります。再生成・取消・削除は対象と警告を確認して実行します。
