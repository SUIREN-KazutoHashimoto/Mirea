# 設定・ジョブ・転送（0.19.0beta）

AndroidアプリとPWAは同じ管理画面を使います。コンテンツ一覧・動画・音楽・本のプレイヤーの配置は今回変更しません。

## 設定

「表示」「アカウント」「保存とオフライン」「アプリと更新」「記録と診断」「アカウントの削除」から選択します。PCでは左のメニュー、狭い画面では上の選択欄を使います。現在の分類だけを表示し、長い内容はその中でスクロールします。閉じるボタンは常に上に残ります。

暗号化保存データと全アセットの一覧・表紙の保存は「保存とオフライン」、本人の詳細閲覧記録の書き出しとマスク済み診断は「記録と診断」にあります。アカウント削除は専用分類に分離します。パスワード確認・所有本棚の引き継ぎ・最後の管理者の保護は維持します。

## サーバー管理

管理者だけが使えます。「運用」「アカウント・本棚」「保守」の順に並べます。スマホでは横に長いタブ列を選択欄へ変更します。

ジョブ管理は、タイトル・処理種類・状態・進捗・受付日時の表です。スマホでは種類をタイトルの下に移し、日時とIDは行を開いた詳細から確認します。検索、状態の絞り込み、受付順／状態順の並べ替えができます。4秒の自動更新で行を作り直さず、展開状態・入力・フォーカスを保持します。

- 現在のジョブ：待機と実行中。画面上の件数は取得済みの範囲です。
- 履歴：完了・失敗・中止。完了は緑、失敗は赤で文字も併記します。履歴からの再実行はありません。
- アセットの再生成：実在するアセットの全件処理と個別検索。既存の警告確認を残し、再生成だけは引き続きパスワード不要です。

各種類の取得上限は最新100件です。全件を永続検索するタスク管理システムではありません。破壊操作・権限変更・バックアップ・サーバー更新のパスワード確認や実行ヘルパーは変更しません。

## 転送状況とアップロード

「進行中」「要確認」「完了」「すべて」を選択し、タイトル・アップロード／ダウンロードで絞り込みます。完了／失敗を絞り込んでも記録は消しません。各行に進捗・状態・詳細・中止／一時停止をまとめます。アップロードの送信完了とサーバー後処理の完了は別です。

アップロードの追加先と原本の設定、ファイル選択を2つの枠に整理します。選択済みファイルが多くても候補欄の中でスクロールできます。既存の送信上限、フォルダ取込、候補検索、警告付き中止・送信済みアセットの確認削除を維持します。

この転送一覧はアプリ／ページの起動中の記録です。再起動をまたぐネイティブ転送は既存の端末通知や保存データの管理から確認します。アカウント・接続先を変えたときは一覧を消去し、前のアカウントの遅れた進捗で復活しないようにします。メニューを閉じても転送は続きますが、ブラウザー終了・OSの強制停止は継続を保証しません。

## 検証と更新

`pnpm test:ui`は新しいヘッドレスブラウザーと一時DBだけを使います。PC、390px、320px、横向きの4条件で設定全分類・管理全項目・転送状態・アップロードを撮影し、横はみ出し・絞り込み・詳細の保持・同一セッションの再接続を確認します。通信は合成データのローカル起点だけに制限し、ユーザーのブラウザー、TrueNAS、実データ、保存済み認証情報へ接続しません。画像はCIの`mirea-management-ui`に7日間保存します。これは実機Androidの描画確認の代替ではありません。

DB schema20のままです。APKは既存の専用署名を維持しversionCode38。更新前に停止状態のdata/media・設定・証明書を全バックアップしてください。コンテナは`0.19.0beta`、公開済みベータへの追従は`beta`を使います。TrueNASへの更新とベータテスターによる実機確認は運用者が行います。
