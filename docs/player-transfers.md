# イコライザー・再生成・端末間の転送確認

> このページは旧リンクからの案内です。Mirea `1.0.0`の手順は、以下の利用者ガイドにまとめています。公開版ごとの変更は[リリース履歴](../RELEASE.md)を参照してください。

| 15帯域のイコライザーとプリセット | [再生・閲覧](user/playback.md) |
| 同じアカウントの別端末で送信状況を見る | [アップロード・転送状況](user/uploads.md) |

作品の詳細には、権限と処理状態に応じて「サムネイルを再生成」を表示します。本棚の所有者、または編集権限を持つアップロード本人が利用でき、サーバー管理者だけの機能ではありません。別の後処理が残っている場合は、その終了後に行います。

カスタム表紙がある場合は保存した元画像から作り直します。失敗した生成物で現在の表紙を置き換えません。表紙の再生成と、動画・音声の再変換は別です。必要な原本や生成済みデータが残っていなければ、再生成だけで失われた品質を復元することはできません。
