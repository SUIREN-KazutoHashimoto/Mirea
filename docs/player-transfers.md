# 音質・未完了修復・シリーズ順序・端末間転送（0.22.0beta）

## イコライザー

Web/PWAは再生コントロールの「イコライザー」、Androidは再生オプションから開きます。25・40・63・100・160・250・400・630 Hz、1・1.6・2.5・4・6.3・10・16 kHzの15帯域を±12 dB、0.5 dB刻みで調整でき、フラット・低音・声・高音のプリセットも選べます。動画と音楽で共通の設定を、その端末に保存します。初期設定はオフです。

設定の変更でメディアのURL・再生位置を変更せず、バックグラウンドやPiPへ移動しても適用を続けます。保存データにも適用します。低音から高音へ横に並んだスライダーで操作します。旧5帯域の設定は対数周波数軸で15帯域へ補間します。全帯域の増幅量を合算して全体を減音せず、大きなピークを保護します。

Web/PWAは[Web Audio](https://www.w3.org/TR/webaudio/#MediaElementAudioSourceNode)を使い、必要になるまで音声グラフを作りません。Web/PWAでは5msの先読みとステレオ連動のピーク保護を行い、AudioWorkletが利用できない場合はブラウザーの圧縮器と出力上限を利用します。Androidは[ DynamicsProcessing](https://developer.android.com/reference/android/media/audiofx/DynamicsProcessing)の15帯域とリミッターを再生セッションだけに適用します。非対応端末では[Equalizer](https://developer.android.com/reference/android/media/audiofx/Equalizer)へ切り替え、端末の対応帯域へ補間し、最大の増幅量だけで音割れ防止の余裕を取ります。この代替処理では音量が下がる場合がありますが、全帯域分を合算しません。端末によって効果の対応帯域や可否が異なります。非対応・適用失敗時は設定画面に表示し、再生は継続します。端末全体の音には適用しません。音声セッションが切り替わった場合は旧効果を解放して接続し直します。

音楽背景は色の光を重ね、動く範囲・濃さ・速さを上げました。Androidは光のシェーダーを再利用します。音楽を停止中、アプリ／ページが非表示、プレイヤーを最小化した場合は停止します。OSの動作軽減設定も尊重します。

## 端末間のアップロード状況

転送状況には、同じアカウントが登録したアセットを1行ずつ表示します。別アカウントの転送は含めません。現在の本棚への編集権限がなくなった場合も、サーバー側の一覧から除外します。ダウンロード記録は端末内です。

0.21.0以降のクライアントは、ファイル本体の前にタイトル・追加先・種類・サイズの待機情報を登録します。転送枠を消費せず、フォルダ内の待機アセットも別端末から確認できます。旧クライアントのアップロードは、サーバーへの送信開始後から確認できます。ファイル本体や端末上の絶対パスを待機情報として送ることはありません。

進捗はサーバーが受信したバイト数を基準にします。送信完了後の変換・表紙生成は別段階として表示します。画面を開いている間は4秒ごとに更新し、「更新」でも再取得できます。以前の完了・失敗記録は100件ずつ追加できます。未送信の待機登録は24時間で期限が切れます。端末を閉じたあともファイル本体を送れるかどうかは、ブラウザーやOSの動作に依存します。

フォルダをまとめた行は表示せず、各アセットから詳細と中止操作を選べます。受信済みの原本・処理中アセットの削除は警告で確認します。完了済みアセットを削除する場合は別途確認します。既存シリーズや、ほかの作品があるシリーズを勝手に削除しません。

## 所有者によるサムネイル再生成

作品の長押し／右クリックから「詳細を表示」を開くと、対象作品に「サムネイルを再生成」が表示されます。対象は、現在その本棚の所有者であるか、編集権限があり自分が追加したアセットです。閲覧者や、ほかの人が追加した作品の編集者には許可しません。サーバー管理者権限は不要です。

警告を確認して実行し、パスワードの再入力は求めません。処理は永続キューへ入り、サーバーの再起動後も再開します。実行中も権限を確認します。同じ作品の後処理が残っている場合は受け付けません。

カスタムサムネイルはアップロード時の元画像からWebPなどを作り直し、元画像とカスタム指定を保持します。動画・音声の原本や作品本体はこの操作で削除しません。音声は保持されている原本から表紙を取得し、ない場合は保存済みの音声を使います。失敗した生成物で既存の表紙を置き換えません。

## 未完了アセットの修復

管理者メニュー → ジョブ管理 → アセットの再生成 →「未完了だけを修復」で対象を確認します。正常なアセット、処理待ち・実行中のアセットを除外します。現在の表紙・変換・プレビューの状態と生成ファイルが基準で、過去に失敗した履歴だけを理由に再生成しません。カスタム表紙は保持原本から再生成し、指定を維持します。動画・音声の原本がない場合は残っている最高品質のデータを使用し、失われた画質は復元できません。利用可能なデータがなければ修復は失敗となり、再アップロードが必要です。

警告確認が必要ですが、再生成にパスワードの再入力は求めません。画面を閉じても継続し、サーバー再起動後も再開します。管理権限が解除された場合は停止します。原本の保持・削除設定、既存の原本再生チケットとダウンロードを維持します。

## シリーズの並び順

標準は名前の昇順で、数字は1・2・10の自然順です。追加と名前変更時も自動で整列します。「シリーズを編集」の並び順から手動指定へ切り替えられ、上下移動でも手動指定になります。「名前の昇順にまとめて並べる」で標準へ戻せます。

今回のDB23移行時に、既存シリーズも一度だけ名前の昇順へリセットします。以後に保存した手動順は再起動・次回更新でも維持します。所属・ラベル・アセット・進行度は変えません。

## 更新と検証

DB23はシリーズに並び順の設定を追加します。DB22の転送待ちメタデータも維持します。既存のアカウント・履歴・進行度・メディア・暗号鍵・証明書を移動／削除しません。更新前に停止した完全バックアップを取得してください。旧コードだけに戻さず、旧版に対応するデータと設定も復元します。

合成データで616件の待機、別セッションの実受信進捗、再起動・ページング・権限変更を確認します。所有者のカスタム画像保持、ブラウザーの音声処理と画面、Androidの効果接続・解放と背景描画も検証します。物理Android端末やTrueNASの利用者の非公開アセットを使う検証ではありません。
