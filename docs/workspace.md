# 設定とアカウント、閲覧画面の入口

> このページは旧リンクからの案内です。Mirea `1.0.0`の手順は、以下の利用者ガイドにまとめています。公開版ごとの変更は[リリース履歴](../RELEASE.md)を参照してください。

左上のMireaロゴからはバージョンとプロジェクト情報を開きます。コンテンツへ戻るための再読み込みボタンではありません。本棚・設定などはサイドバーまたはメニューボタンから選びます。

個人設定ではテーマ、保存データ、アプリ更新、本人の記録を扱います。名前・メール・パスワードの変更には現在のパスワードが必要です。変更後は他の端末でログインし直します。アカウント削除はログアウトと異なり、本人の記録や保存登録を削除する操作です。

作品を開くと、本はリーダー、動画・音楽は専用プレイヤーへ移ります。操作メニューは通常コンテンツへ重ね、固定した場合は領域を確保します。音楽・動画の画面を閉じてライブラリへ戻る操作と、再生を終了する操作は区別します。
