# 設定・アカウント・閲覧画面（0.2.0beta）

WebとAndroidは同じUIです。PCはサイドバーの「設定」、スマートフォン幅では右上の設定ボタンから開きます。

## アカウント

表示名・メール・パスワードを変更できます。現在のパスワードが必須で、新しいパスワードは12〜128文字。保存すると現在の端末へ新セッションを発行し、全旧セッションと再生チケットを失効させます。メールの所有確認・パスワードリセットメールは未実装です。メール変更でサーバー管理権限は変わりません（UUIDの明示allowlist）。

削除は現在のパスワード・メール再入力・確認チェックが必要です。共有されている、または作品が残る管理本棚は、先に別の既存メンバーへ管理を引き継いでください。自分だけの本棚は作品を明示削除して空にしてから退会することもできます。本棚の共有設定に「管理を引き継ぐ」があり、元管理者は編集者になります。最後のサーバー管理者は削除できません。アップロード中／処理中も退会を拒否します。

退会はアカウント・所属・セッション・進行度・暗号化ダウンロード登録・本人の詳細閲覧ログ（イベント／ページ／区間集計も含む）をトランザクションで削除します。自分だけの空の本棚は削除します。他人の記録、共有本棚の作品・原本・サムネイル・シリーズは保持し、退会者がアップロードした作品は uploaded_by=NULL になります。匿名集計も削除された本人のデータを以後含みません。元に戻せません。

この端末の当該サーバー＋アカウントの暗号化パッケージと未送信記録・進行度も消去します。消去失敗は画面で通知します。他の端末の保存領域、既存の運用バックアップは遠隔消去できません。登録の無い暗号化データに鍵は発行しませんが、既に開かれた短時間のRAM上の認可は期限まで残ることがあります。詳細ログの無期限保存は通常運用の方針で、本人の退会は例外です。

## 表示とダウンロードリンク

テーマは「端末に合わせる」「ライト」「ダーク」。同じ端末のlocalStorageに保存し、OS連動時は変更も追従します。本のページや動画の原色は変えません。ログイン画面・ライブラリ・設定に、当該リリースのHTTPS APKリンクがあります。APKはテスト署名のベータです。署名差異で上書きできない場合のアンインストールは端末所有者が判断してください。

## 閲覧画面

作品を開くとブラウザー／アプリの表示領域全体を使います。別ウィンドウや浮いたモーダルではありません。戻るボタンで本棚へ戻り、任意の全画面ボタンでOS／ブラウザーのフルスクリーンにします（対応端末のみ）。通常表示ではEscでも閉じます。OS全画面時は最初のEscは全画面解除です。

動画は標準HTML videoのデコード／Range取得を使い、controlsは無効にしてMireaの操作バーを表示します。再生・停止、再生位置、±10秒、音量／消音、0.5〜2倍速、再接続、全画面を操作できます。プレーヤー本体にフォーカスするとSpace/K、左右キー、上下音量、M、Fも使えます。再接続は新しいチケット／保存済みデータのオンライン認可を取得し、位置を戻します。自動再生には端末側の制約があります。速度・音量は端末間同期しません。

本はPDF・画像で共通の読書室UIです。デフォルトは高さと幅の両方に収まるページ全体表示。倍率は100/150/200%も選択でき、拡大時はスクロールできます。目次はPDFの内部ページ宛先のみを扱い、外部URLは開きません。ページ一覧は現在位置周辺の最大100件、章の目次は最大200件です。番号入力と進行度スライダーでは全ページへ移動できます。画像本はページ一覧を使います。

左右の端タップ、横スワイプ、左右キーでページを送ります。右開き設定は方向を反転し、PageDown/PageUpは常に次／前ページです。拡大による横スクロールがある場合は横スワイプで誤ってページを送りません。最終ページからは明示的な「次の作品」でシリーズを進めます。自動で本を飛ばしません。見開き／ページめくりの3D演出は未実装です。

続き位置・倍率・スクロールと詳細閲覧記録、保存済み暗号化データを開くたびのオンライン認可、シリーズのアクセス再確認は従来どおりです。

## API（/api/v1）

| 操作 | 内容 |
| --- | --- |
| GET /account | 本人情報、管理本棚の作品数／人数、進行中アップロード数、最後の管理者か |
| PATCH /account | currentPassword必須、name/email/newPassword任意。新しいuser/token/expiresAt |
| DELETE /account | currentPasswordとconfirmEmail必須、成功204 |
| PUT /shelves/:id/owner | 管理者限定。currentPasswordと既存メンバーのuserId、成功204 |

全てBearer認証必須。変更系は現在パスワードを照合し、非同期ハッシュ処理後もセッションと競合を再確認します。失敗は400入力、403パスワード／権限、404本棚／メンバー非公開、409競合・退会不可。設定APIはIP当たり毎分10回の上限です。DB v9移行前には停止中にDATA_DIR全体をバックアップしてください。
