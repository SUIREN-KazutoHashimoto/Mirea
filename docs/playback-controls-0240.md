# Web/PWAの再生操作とメディア保存量（0.24.0beta）

動画・音声を一覧から開くと、続き位置を復元して再生を始めます。ブラウザーが自動再生を制限する場合は中央の再生ボタンから開始できます。起動時に復元する停止中のミニプレイヤーは、引き続き自動再生しません。

シークバーのドラッグ終了と画面更新が競合し、選んだ再生位置を元の位置で上書きしていた問題を修正しました。音声と動画の再生操作列に前／次の作品ボタンを追加し、シリーズやプレイリストの並び、リピート、シャッフルと連動します。移動できない方向はボタンが無効になります。作品を切り替える際はアクセス権と進行度を確認します。

音量・消音・再生速度は変更時にブラウザー内へ保存し、次の作品や再読み込み後にも引き継ぎます。ログイン先とアカウントごとに区別します。動画を長押ししている間の一時的な2倍速は、保存する速度として扱いません。保存領域が利用できない場合も、再生を止めず同じ画面内で設定を引き継ぎます。

Android版と照合したWeb/PWAの操作は、前後の作品、10秒戻る／進む、リピート、シャッフル、イコライザー、速度、対応する動画の画質・字幕・チャプター、PiPとバックグラウンド再生です。端末の画面回転やOSの再生機能にはブラウザー側の対応範囲が適用されます。

管理画面の「サーバーの状態」に、既存の基本メディア合計に加えて「メディア保存量（原本・派生データを含む）」を表示します。対象はDATA_DIRのthumbnails／previewsと、MEDIA_DIRのuploads／videos／originalsです。全画質、HLS、表紙の原本、動画プレビュー、未完了転送も含みます。DB、暗号鍵、バックアップは含みません。ファイルの内容を読まずに容量のみを集計し、管理画面へパスや作品名を返しません。リンク先へは移動せず、同じ実体のハードリンクは一度だけ数えます。圧縮・重複排除などを適用した後の物理ディスク使用量とは異なる概算です。

大きな保存領域の集計中も概要画面を開けます。集計結果は最大1分間再利用します。既存データとDBスキーマ24、APK署名、証明書、暗号鍵を保持します。
