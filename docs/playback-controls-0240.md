# 再生操作と保存容量の表示

> このページは旧リンクからの案内です。Mirea `1.0.0`の手順は、以下の利用者ガイドにまとめています。公開版ごとの変更は[リリース履歴](../RELEASE.md)を参照してください。

Web/PWAで動画・音楽を選ぶと続き位置を復元し、再生開始を試みます。ブラウザーに制限された場合は再生ボタンを押します。起動時に復元される停止中の小型プレイヤーは自動再生しません。

シークバー、前後の作品、10秒移動、速度、リピート、シャッフル、イコライザーを使えます。音量・消音・速度は、この端末の同じサーバー・アカウントで保持します。長押し中の一時的な2倍速は保存速度を変えません。

管理者向けの保存容量には「基本メディアの合計」と、原本・派生データを含むメディア保存量があります。後者には表紙・プレビュー・変換済み画質・未完了転送などを含みますが、DB・鍵・バックアップは別です。ファイルの論理的な合計であり、ストレージの圧縮・重複排除後の物理使用量と一致するとは限りません。
