# 0.17.0beta — 名前の整合性と更新情報の保守

同じ本棚の最上位、または同じシリーズ直下では、アセットのタイトルを一意にします。拡張子や種類が違っても同じタイトルは重複です。前後の空白を除きUnicode NFCで比較し、大文字小文字は区別します。別シリーズ・別本棚の同名は許可し、本棚の名前は制限しません。

アップロード受付で処理中・再試行待ちの同名も確認し、公開直前に再確認します。シリーズ編集で作品を移す・解除する場合や、作品を残してシリーズを削除する場合も最終状態を検査します。衝突時は409で拒否し、既存の作品を上書き・自動改名・削除しません。追加先シリーズが削除・満杯になり最上位へ保存する場合も同じ検査を行い、衝突する処理は失敗として残して利用者の整理を待ちます。

既存の同名シリーズ・同名アセットはそのまま保持します。本棚の所有者・編集者に、解消するまでライブラリ上部へデータ不整合のメッセージを表示します。閲覧専用ユーザー、所属しないサーバー管理者には詳細を開示しません。オフラインでも保存済み一覧の時点の重複を表示します。シリーズ編集、アセット詳細の「タイトルを変更」で手動整理できます。タイトル変更は本体・記録・続き位置・暗号鍵を変更しません。

更新情報の再署名はAPK本体の再署名ではありません。既存の専用鍵で更新JSONの発行日・有効期限だけを更新し、APKのバイト列・versionCode・署名者を維持します。有効期限は最大7日のままです。公開済みの明示した1リリースずつ更新し、旧JSONは削除せず退避します。秘密鍵は配布用PCの外部保管先に留めます。定期実行はPCとCodexアプリの稼働、GitHubへの認証・HTTPS接続、実行権限が必要です。停止・失敗時は自動更新情報が失効する可能性があります。

Play Protectの「有害なアプリをブロックしました」はGoogle側の有害性判定であり、Mireaの更新JSONの期限とは別です。APKの署名が有効でもGoogleの判定を保証しません。署名鍵・パッケージ名を変えたり、Play Protectを無効化したりして回避しません。対象APKの版・ハッシュと警告詳細を確認し、必要なら所有者の承認後に公式再審査へ進みます。個人アセット・履歴をGoogleへ送信しません。

DB v19を維持します。更新前に停止中のdata全体と分離時のmedia全体、設定・証明書をバックアップしてください。WinVAI01をCodexの検証に使い、TrueNASのデータは診断・動作確認に使用しません。Androidはcode34、既存署名で上書き更新します。
