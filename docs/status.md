# 対象版と検証範囲

この文書の対象は **Mirea 2.0.0beta** です。内部版は `2.0.0-beta`、Android表示版は `2.0.0beta`、versionCodeは54、DBスキーマは26です。ローカルAIを追加した最初の2系ベータで、AIは初期状態では無効です。公開状態はGitHub Releasesの対象タグで確認します。安定版1.0.0の文書はそのタグを参照してください。

## 2.0.0betaのローカルAI

タグ、OCR、音楽構成、動画章、全文・意味検索、手動訂正、永続解析ジョブ、解析情報の端末保存を追加しています。モデル重みは別途導入します。AI表を追加したDBスキーマ26を使用するため、既存データを使う前に完全バックアップが必要です。旧版と同じDBを交互に起動しません。

[導入](operations/ai.md)、[利用](user/ai.md)、[実装設計](design/ai-implementation.md)で、この版に対応する操作と制約を説明しています。CPUの実モデル実行、合成データによるAPI・画面・状態遷移の確認と、Android実端末・Vulkan実GPU・Linuxコンテナの実行確認は区別します。後者について、コードやビルド定義の追加だけを実機成功とは扱いません。

## 配布版を使うとき

[GitHub Releases](https://github.com/SUIREN-KazutoHashimoto/Mirea/releases)で選んだ版の配布物と、そのタグの文書を組み合わせます。ブランチのコードを、同名の公開コンテナに含まれていると考えないでください。コンテナの固定タグと追従タグの違いは[更新手順](operations/updates.md)を参照してください。

Releaseの公開前のブランチを読む場合、文書にある版番号だけで配布済みとは判断しないでください。公開状態・配布物・対応するコミットはGitHub Releasesで確認します。

## 基盤となる1.0.0で追加・改善した範囲

- 大きなシリーズを扱う操作、取り込み候補の確認、再試行、一覧の再利用と負荷低減。
- 保存済み作品・一覧の扱い、読書の先読み、再生・接続変更時の継続性の改善。
- WebViewの読み込み範囲、ネイティブAPI、端末ファイル共有・バックアップ、転送の権限保持、更新元切替の検証の強化。
- APK配布前のアーカイブ検査、依存関係の修正、文書体系の再整備。
- 起動・アカウント切替・端末保存解除の競合、配信世代のダウンロード登録、シリーズ削除対象とプライベート本棚の認可判定の修正。
- バックアップ中の原本回収・表示用ページ生成の競合修正と、復元後のダウンロード確認に必要なファイル時刻の精度保持。
- 同じ版番号のベータ版から正式版への更新案内、第三者ライセンスの同梱・表示、完成品サーバーアーカイブの導入・移行手順の整備。

具体的な変更は[1.0.0のリリース履歴](../RELEASE.md#100)、操作は[利用ガイド](README.md#利用)、実装の責務と制約は[設計書](design/overview.md)を参照してください。

## 1系以前から2系への移行

更新前にdata/media・設定・証明書を同じ停止時点で完全バックアップします。先にサーバーを2.0.0betaへ更新し、次に同じ署名のAndroid 2.0.0betaへ上書き更新します。アプリとサーバーのメジャー番号が違う間は作品を利用できませんが、更新確認の通信は利用できます。アンインストールや保存領域の初期化は不要です。

`beta`は2系ベータ、`stable`は正式版1.0.0を指します。2系へ進む場合は完全バックアップ後に固定タグ`2.0.0beta`または`beta`を再取得・再作成します。2系のDBへ旧版を直接戻さず、切り戻す場合は旧コードと更新前バックアップを復元します。

2.0.0betaの公開日時をもって、最新メジャー以外の1系以前のAPK更新情報の定期再署名を終了します。既存Release・APK・更新JSON・鍵は削除しません。旧JSONは現在の有効期限を過ぎると更新案内に使えなくなります。[更新と切り戻し](operations/updates.md)

## 検証結果の読み方

合成データを使ったAPI・状態遷移の自動テスト、PC／スマートフォン幅のブラウザー操作、旧版からの更新・復元、管理画面バックアップの復元、Androidの単体検査とAPKビルドを区別して検証しています。旧版更新には、現在の依存関係を共用する公開0.25.0betaソースの結合試験と、公開済み0.25.0betaコンテナそのものからの更新・旧版への復元試験があります。コンテナ試験は[PR #41の正式CI](https://github.com/SUIREN-KazutoHashimoto/Mirea/actions/runs/41382836594)で単一保存先・data/media分離構成の両方が成功しました。この結果を後続変更のCI成功の代わりにはせず、公開対象コミットを別途確認します。

**Android 17実端末での確認は未実施です。** メーカー固有の省電力・PiP・LTE切替・Play Protect再判定について、ビルドや単体テストの成功を実機確認の代わりとはしません。Play Protect警告の原因特定や判定解除も確認できていません。検証手順は[テストガイド](development/testing.md)、Play Protectの確認範囲は[調査記録](security/play-protect.md)にあります。

公開版・開発中の比較では、版番号だけでなくコミットと実際に配布したAPK／イメージのハッシュを記録します。正式CIの結果と配布物の検証は、対象コミットに対応する記録で確認してください。
