# 没入表示・スワイプ・EPUB

この変更はWebとAndroidで共通の読書／動画画面に適用されます。

## コンテンツを大きく表示

ヘッダー、続き位置、シリーズ、読書ツールバーはコンテンツに重ねて表示します。表示／非表示で本文・映像の領域を縮めません。最初は非表示です。右上の「•••」、本の中央タップ、`I`キーで切り替え、PCでは上端にマウスを置いても表示できます。Tab操作でもメニューを表示します。動画の操作パネルは再生中に自動で隠れ、シリーズの次作品へのカウントダウン中は取消操作を隠しません。

PDF・画像の「ページ全体」は縦横両方に収め、周囲の余白を最小限にします。原本の縦横比は維持するので、縦長の本を横長の画面に表示した際の左右余白などは残ります。ブラウザーのタブ・アドレスバーも隠したい場合は任意の全画面ボタンを使います。

## 本の操作

- 横スワイプ／マウスドラッグ、左右端のタップ、矢印／PageDown・PageUpでページ送り。
- 左開きは左へのスワイプ、右開きは右へのスワイプで次へ。PageDownはどちらも次へ。
- 縦スクロール、複数指操作、その場の長押し、横スクロールが必要な拡大中は誤ってページをめくりません。ゆっくりした横スワイプ／ドラッグも受け付けます。
- 目次・番号・進行度から移動でき、最終ページの次操作でシリーズの次の作品へ進みます。

## 電子書籍形式

新たに**DRMなしのリフロー型EPUB 2／3（`.epub`、`application/epub+zip`）**に対応します。アップロード、本棚・シリーズ、表紙サムネイル、章の目次、ページ送り、文字サイズ、続き位置、閲覧ログ、暗号化ダウンロードを利用できます。EPUBは1ファイルずつアップロードしてください。

本文は画面サイズ・文字サイズに応じてページに分けます。表示中の「ページ」は端末によって変わるため、再開位置は**章番号＋章内の相対位置＋文字サイズ**を保存します。端末やサイズが変わると近い位置のページを復元します（同じ単語での厳密な復元ではありません）。入力番号／スライダーは章移動、矢印／スワイプは章内のページ移動です。閲覧ログのpageは章番号で、x／widthが章内の表示範囲を表します。章ごとの表示時間に加え、章内の表示範囲の変化も生ログに残ります。

安全のため、書籍のJavaScript、外部通信、任意CSS、フォーム、動画／音声、外部リンクは実行しません。本文・見出し・ルビ・リスト・表・内部リンク・JPEG／PNG／WebP／GIF由来の静止挿絵を安全な要素へ変換し、端末のフォントで表示します。元の組版・縦書き・独自フォント・固定レイアウトの完全再現、DRM解除、MOBI／AZW／CBZ／CBRは対象外です。標準のフォント難読化だけがある本は、フォントを使わず読みます。表紙画像がなければタイトル付きの表紙を生成します。

### 制限と保存

- 圧縮EPUB 64 MiB以下、ZIP全体の展開サイズ48 MiB以下、最大5,000エントリー・500章。
- XML／HTMLは各2 MiB以下、各リソース16 MiB以下。画像は最大4,000万画素を検証し、閲覧用には最大1,800×2,400pxのJPEGへ変換します。原本EPUBは変更しません。
- 閲覧データは最大32 MiB。Web／Androidとも開く際にこのデータを読み込みます。EPUBの章単位ストリーミングは未実装です。動画のRange配信、PDFの必要範囲取得はそのままです。
- ZIPをファイルシステムへ展開しません。危険なパス、シンボリックリンク、重複、暗号化、過大展開、CRC不一致、DTD等を拒否し、時間・メモリー制限付きワーカーで解析します。
- サーバーは原本を`uploads/<UUID>`、安全な閲覧データを`uploads/books/<UUID>/book.json`へ保存。アセット削除時に両方削除します。
- ダウンロードは原本EPUBではなく、本文・挿絵を含む閲覧データをAES-256-GCMで暗号化して保存します。開くたびのオンライン認可、鍵のメモリー限定保持は他形式と共通です。

## API・移行

既存の単発／分割アップロードにEPUB MIMEを追加。`GET /api/v1/items/:id/epub`は認証・本棚権限確認後、安全なJSONを`application/vnd.mirea.epub+json`、`Cache-Control: no-store`で返します。原本の`/content`は認証付きRange取得が可能です。item.kind／ダウンロードmanifest.kindは`epub`。pageCountは章数です。`GET /config`のmaxEpubBytesはEPUB固有の圧縮サイズ上限です。

DBはv10へ更新し、itemsのEPUB MIMEを許可します。v9以前のアカウント・共有・原本・ページ・ログ・進行度・暗号化登録・シリーズを保持します。**旧0.2系（v9）のサーバーはv10を開けません。** 更新前にサーバーを止め、DATA_DIR全体（鍵を含む）をバックアップしてください。ロールバックは旧コード＋更新前DATA_DIRを組み合わせ、自動ダウングレードは行いません。
