# 本の表示とEPUB

> このページは旧リンクからの案内です。Mirea `1.0.0`の手順は、以下の利用者ガイドにまとめています。公開版ごとの変更は[リリース履歴](../RELEASE.md)を参照してください。

PDF・画像本はページ端のタップ、横スワイプ、前後ボタンなどで読み進めます。拡大中に横へスクロールする操作と、ページ送りを区別します。メニューを固定すると操作領域を確保でき、固定しなければ作品へ重ねて表示します。

EPUBはDRMのないリフロー型EPUB 2/3に対応します。章の目次、文字サイズ、続き位置、端末保存を使えます。複数のEPUBファイルを選んだ場合も、それぞれ別の作品として追加します。

EPUBの画面上のページ数は画面幅と文字サイズで変わります。続き位置は章内の相対位置を使うため、違う端末で同じ文字の位置まで厳密に復元するわけではありません。ページ番号・バーによる章移動と、章内のページ送りを使い分けます。

書籍内のJavaScript・外部通信などは実行しません。元のフォント・縦書き・固定レイアウトの完全再現やDRM解除は対象外です。原本と、安全に閲覧するために変換したデータを区別します。
