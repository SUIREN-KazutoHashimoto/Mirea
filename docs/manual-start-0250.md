# 待機中の送信・ジョブを手動で開始する

> このページは旧リンクからの案内です。Mirea `1.0.0`の手順は、以下の利用者ガイドにまとめています。公開版ごとの変更は[リリース履歴](../RELEASE.md)を参照してください。

転送状況の送信待ち項目から「強制開始」を選ぶと、通常のアップロード枠とは別に、1ユーザーにつき同時に一つを開始できます。同じアカウントの別端末から確認・指示する場合も、一つの追加枠を共有します。

これは回線を速くする設定ではありません。選択元のファイルを保持している端末が送信できる必要があります。元のブラウザーを閉じた後に、別端末へファイル本体を自動で移す機能ではありません。

サーバー管理者は、ジョブ管理の待機中ジョブから手動開始できます。対象ジョブの状態・依存関係・権限を確認してから実行します。既に動いている処理の複製や、安全検査を省略する操作ではありません。
