PDF用のWorker・フォントは同梱し、外部CDNには依存しません。動画検証用の素材はブラウザ内で生成したもので、利用者の個人ファイルは使用していません。プレビュー用データはGit管理対象外の `data/` にあります。

監査で検出したPDF.jsと静的配信ライブラリの問題は、`pdfjs-dist 6.4.299` と `@fastify/static 10.1.6` への更新で解消しました。検証時点の監査結果であり、将来の未発見の問題がないことを保証するものではありません。

自動テストは別の一時データ領域を使い、通常の `data/` には変更を加えません。認証、所属先の分離、多対多の本棚所属、管理者保護、権限変更、PDF／動画のアップロード、サイズ・形式制限、Range / HEAD、チケットの範囲制限、共有解除・ログアウト後の拒否、再起動後の保持を検証しています。

追加テストでは、複数形式の画像を1冊として保存すること、送信順の保持、EXIF表示寸法、原画像を再圧縮せず保持すること、画像ページ・サムネイルの権限確認、共有解除後の拒否、壊れた途中ページで半端な本が残らないこと、画像本の削除時のファイル回収も検証しています。
