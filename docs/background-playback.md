# PiP・バックグラウンド再生

動画はPiPとバックグラウンド再生、音声はバックグラウンド再生に対応します。音声アセット対応と合わせて0.3.0betaに収録します。0.2.3betaの旧APKには含まれないため、新しい専用署名APKへ更新してください。

## Web

動画プレーヤーにPiPボタンを追加します。標準Picture-in-Picture APIまたはSafariのpresentation modeが利用できる場合だけ表示します。ウィンドウを閉じると元のプレーヤーに戻り、閲覧を終了するとPiPと再生も終了します。音声にはPiPボタンを出しません。

動画・音声の「背景」ボタンでライブラリに戻れます。下部の再生中バーからプレーヤーへ戻る／停止を選べます。タブを切り替えただけでは停止せず、Media Session APIの再生・一時停止・シーク・停止・再生位置表示に対応します。シーク／停止などの機能は各ブラウザーの対応状況に従います。

**タブを閉じた後、ブラウザーを終了した後、OSがタブを凍結・破棄した後までの再生は保証しません。** 特にモバイルブラウザーの画面消灯・省電力時にはOS側で停止する場合があります。自動再生制限、PiPの非対応／禁止設定を回避しません。ブラウザー設定や証明書の信頼設定は変更しません。

## Android

Capacitorの画面から、アプリ内の専用ネイティブ再生画面と`mediaPlayback`フォアグラウンドサービスを起動します。MediaPlayer・MediaDataSource・MediaSessionを使用し、再生・続き位置・詳細ログはWebViewのタイマーから独立させます。Activity、Serviceとも外部アプリからの直接起動は許可しません。

- 動画のPiPボタン、再生中にホームへ移動した際のPiP（対応端末）。PiP中は映像以外のUIを隠します。
- 動画・音声の「背景再生」、画面消灯時の再生維持、通知／ロック画面／ヘッドセットからのメディア操作。
- ライブラリへ戻って再生を継続する操作と、再生中バー。
- 再生・一時停止・10秒前後・シーク・速度・消音・動画画質選択・再接続。端末の音量キーはメディア音量を操作します。
- 音声フォーカス喪失やイヤホン取り外しで一時停止／ダッキング。恒久的なフォーカス喪失後に勝手に再開しません。
- 同じシリーズの次の動画・音声へ継続できます。次が本の場合は案内を出して停止し、ライブラリから本を開きます。バックグラウンドで本を自動表示しません。
- 一時停止のまま5分間バックグラウンドに置いたサービスは終了します。明示停止／ログアウト／接続先変更でも停止し、端末再起動後に認証なしで自動再開しません。
- 再生サービス中はアプリ自動更新のインストール／APK取得を保留します。画面破棄でこの保留が解除されないよう、閲覧の保留フラグとは分離しています。

CPUのWakeLockはMediaPlayerの実再生時にだけ保持します。オーバーレイ権限や電池最適化除外を要求せず、メディアセッション通知を使います。OSの強制停止やメーカー独自の電池制限からの復帰は保証しません。

## Android再生画面（0.4.2beta）

動画はヘッダーや大きな固定ボタンで領域を分割せず、アスペクト比を維持した映像へ操作を重ねます。横長動画は横画面、縦長動画は縦画面を初期表示とし、上部の回転アイコンから縦／横を切り替えられます。手動の向きはプレーヤーを閉じるまで優先し、切り替え時に再生ソースを開き直しません。Android 16以降の大画面・マルチウィンドウではOSが向きの指定を適用しないことがあるため、現在のウィンドウ寸法に合わせて再配置します。OSの互換性設定や画面回転設定を変更しません。

再生中の操作は3.5秒で隠れ、画面タップで再表示します。一時停止・読み込み中・シーク中・メニュー表示中・TalkBackのタッチ探索時には自動で隠しません。画面端からのスワイプでシステムバーを一時表示できます。映像表示中の実再生時だけ画面スリープを抑え、音声再生は画面消灯を許可します。

音声は専用画面でジャケット・曲名・再生位置・前後の作品／10秒移動・再生／一時停止を表示します。横幅が広い場合はジャケットと操作を左右に配置し、短い／文字が大きい画面ではスクロールできます。速度・画質・PiP・消音・連続再生・再接続等は「⋮」に整理します。音声には画質・PiP・回転を出しません。×は停止して戻り、「ライブラリへ戻る（再生を継続）」や「バックグラウンドで再生」は再生を維持します。

Android ViewをRobolectricのネイティブ描画で縦・横・小画面のPNGへ描画し、主要操作の配置・表示・タップ、PiPでのUI非表示をテストします。回転方針・比率維持・自動非表示の時間と例外も単体テストします。これはAndroid実機でのメディアデコード・PiP移行・物理回転の検証とは別です。

参照: [Androidの没入表示](https://developer.android.com/develop/ui/views/layout/immersive)、[Android 16以降の向き指定と大画面](https://developer.android.com/develop/adaptive-apps/guides/app-orientation-aspect-ratio-resizability)。

## ストリーミング・暗号化保存（配信方式）

ネイティブの配信は、認証付きの256KiB Range読み込みを行い、最大2ブロックだけメモリーにキャッシュします。HTTPS限定・同一サーバー限定・リダイレクト拒否・標準の証明書検証を使用します。動画の画質別MP4にも同じACLとRange制約を適用します。

ダウンロード済みの場合、初回のネイティブ再生時に既存IndexedDBの**暗号文だけ**をアプリ専用ディレクトリへコピーします。サーバーへのオンラインopenで毎回権限を確認し、AES-256-GCMキーはサービスのメモリーにだけ置きます。チャンク番号・パッケージID・長さをAADに結び、必要なチャンクだけ復号します。平文の動画・音声やキーをディスクへ保存しません。サーバーのopenに失敗した場合にオンライン配信へ黙って切り替えません。

ネイティブ側の暗号文コピーには追加の保存容量が必要です。ダウンロード削除／アカウント削除時にはそのコピーも削除します。ログアウトでは既存方針どおり暗号文を残し、キーと再生を終了します。

## 続き位置と詳細ログ

通常表示・PiP・バックグラウンドを区別し、schemaVersion 1のイベントに`pictureInPicture`、`backgroundPlayback`、`pipMs`、`backgroundMs`を追加します。`watchMs`は実際の再生区間で、表示・フォーカス時間を水増ししません。シーク、停止、バッファ待ち、長時間の不明なタイマー停止は視聴時間に加算しません。既存の生ログ再送のハッシュ互換性も維持します。

Androidは端末専用のSQLite送信待ちキューを持ち、ユーザー・接続先ごとに分離します。トークンやコンテンツキーを記録しません。通信失敗時は同じイベントID／進行度更新IDで再送し、他端末の更新との409競合では勝手に上書きしません。本人以外へ詳細を公開しない匿名集計の境界は変更しません。

## 検証と制限

WebのOS操作・PiP・バックグラウンド計測、サーバーの不正な時間加算拒否、画質別RangeのACL、Androidのコンテキスト検証・AES-GCM改ざん検出・区間計測・進行度再送を自動テストで確認します。Androidのコンパイル／Lint／デバッグAPKビルドも確認します。

接続可能なAndroid実機・エミュレーターはなく、実機でのホーム移動・画面消灯・Bluetooth・PiP終了ジェスチャーは未検証です。配布前にAndroid 10／12／13／15／16等で確認してください。
