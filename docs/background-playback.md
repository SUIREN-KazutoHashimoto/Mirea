# 小型表示・PiP・バックグラウンド再生

> このページは旧リンクからの案内です。Mirea `1.0.0`の手順は、以下の利用者ガイドにまとめています。公開版ごとの変更は[リリース履歴](../RELEASE.md)を参照してください。

音楽・動画のプレイヤーからライブラリへ戻っても、再生操作を小さな表示に残せます。サムネイルからプレイヤーへ戻り、最小化は表示を畳む操作として使います。再生を止めたい場合は一時停止・終了操作を使ってください。

| 環境 | 再生を支える仕組みと制約 |
| --- | --- |
| Web/PWA | ブラウザー内のプレイヤーを継続。PiP・OSのメディア操作はブラウザーの対応範囲で利用 |
| Android APK | 独立した再生サービス、通知・ロック画面の操作、対応端末のPiPを利用 |

Web/PWAのタブ終了やOSによる停止後までの継続は保証しません。Androidも強制停止や端末再起動後に勝手に再生を始めるものではありません。音声フォーカスやイヤホンの取り外しによって一時停止する場合があります。

通信が不安定な場所では、先に作品の保存を完了しておくと通信への依存を減らせます。モードの手動切り替えを毎回行う必要はありません。
