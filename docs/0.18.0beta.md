# 0.18.0beta — 転送・オフライン表示・表紙の改善

## アップロードと後処理

送信枠はサーバーの永続キューへの受付で解放します。ブラウザーとAndroidの転送ジョブは、サムネイル・変換・配信画質の完成を監視し続けません。全件「送信完了」になればタブを閉じられます。変換の失敗・進捗は「アップロード処理」、転送の詳細を開いた際の状態取得、管理画面で確認します。送信前・送信途中のブラウザー終了や端末の強制停止まで継続を保証するものではありません。

新しいサーバーはプロトコルv2を通知し、ブラウザーは最大4分割、Androidは最大2分割を1アップロード内で並列転送します。各分割のSHA-256、再開時の受信済み分割の全バイト検証、権限・同時送信数制限を維持します。旧サーバーには従来方式を使います。Androidの新方式は送信前の全ファイル読み取りを小さなサンプルに変更し、実際の送信時には全分割を検証します。同名・サイズ等が一致する保留中の候補を再開する場合も内容の不一致は拒否し、既存データを勝手に置換しません。

連続した送信中は新規の後処理開始を短時間保留し、転送を優先します。既に実行中の変換を強制停止するものではなく、HDD・CPU・ネットワークの上限によって速度は変わります。数値の速度保証はしません。WinVAI01でダミー500MiBを読み出し・ハッシュ計算・HTTP送信・永続受付する単回比較は、旧版1並列33.70秒、新版4並列11.60秒でした。ループバックで他の検証も稼働中の値であり、TrueNAS・Cloudflare経路や3Gbpsの実効速度を示す測定ではありません。永続ジョブは再起動後も復旧し、後処理の並列上限（既定5）を守ります。

一括選択は合計1,000ファイルまで。画像本も最大1,000ページです。管理者の一括アセット上限がそれより低い場合は低い設定を尊重します。追加先シリーズに処理中の作品も非活性で表示し、本棚直下には混ぜません。フォルダ列挙・候補確認・追加先の準備に進捗を表示します。Androidの列挙はUIスレッドの外で実行し、候補一覧は100アセットずつ描画します。

## 表紙と動画プレビュー

カスタムサムネイルを再生成するときは、保存したアップロード原本から派生画像を作ります。原本は変更・削除しません。表示用WebPは長辺1,024px以下、縦横比維持、拡大なしです。カスタム表紙の原本が古い環境で既に失われていた場合、残っている派生画像を別名で保持して利用します。画像まで失われた場合は再アップロードが必要で、動画・PDFの自動表紙へ無断で戻しません。

動画の自動表紙に使用した時刻をDBへ保存し、その位置から最大10秒・無音のプレビューを生成します。短い動画は残り区間だけです。既存の時刻不明な動画はプレビュー再生成時に自動表紙と時刻を揃えますが、カスタム表紙の選択は維持します。古い6秒プレビューは新仕様の生成が終わるまで配信しません。

## オフラインと画像本

オフライン起動は、保存した本棚・入れ子シリーズ・表紙を先に表示し、メディアごとの期限検証は後から少数並列で進めます。検証前の作品は非活性です。Androidの大量の暗号化データ取り込みを一覧の初回表示から切り離します。大きなカタログ全体を時計確認のたびに書き直さず、小さな暗号化チェックポイントを更新します。7日期限、時計巻き戻し検出、アカウント・サーバー分離は維持します。

画像本は現在ページを優先して最大4ページずつ、全ページを先読みします。メモリーのページキャッシュは64MiBに制限し、残りはセッション専用AES-256-GCM鍵で暗号化した一時領域から読みます。鍵は永続保存せず、読書画面を閉じると暗号化ページを削除します。異常終了で残った暗号文は翌日以降の起動時に回収します。先読みは閲覧回数・ページ滞在の記録に含めません。保存領域の制約がある場合はメモリー内先読みに縮退し、容量に応じて再読み込みすることがあります。

## 更新

DB v20へ追加型移行し、動画の表紙位置とプレビュー仕様のテーブルだけを追加します。既存レコード・ダウンロード鍵・証明書・APK署名者は維持します。Android code35。更新前にサービスを停止してdata全体、分離時はmedia全体、設定・証明書をバックアップしてください。旧版への復元は旧コードと対応する更新前バックアップをセットで行います。Codexの検証はWinVAI01で行い、TrueNASの利用者データは使いません。

Play Protectの判定解除を保証する変更ではありません。保護機能やTLS・署名検証を無効化しないでください。
