# 再生モード・外観（0.8.0beta）

- Web／Androidの音楽・動画に「リピートなし／単体／シリーズ」と独立したシャッフルを用意。音楽はインライン、Android動画は再生オプションから選択。Web動画にも同じ設定がある。
- 単体リピートは同じプレイヤーを先頭へ戻して継続し、アクセス権・暗号化保存の7日期限を迂回しない。MP4／音声は非同期シーク完了後に再開し、途中の一時停止・停止で再開予約を取り消す。
- シリーズリピート／シャッフルの対象はシリーズ内の動画・音声。本はこのモードの候補にしない。通常の混在シリーズの移動・本の連続閲覧は従来どおり。
- シャッフルは一巡まで重複しない袋方式。前へ／次へは実際に通った履歴をたどり、シリーズリピート時だけ次の巡回へ進む。履歴はメモリー内・最大2,000件。サーバーやブラウザー永続領域へ再生候補の一覧を新たに保存しない。
- モードの設定だけをユーザー／接続先別に保存する。再生中・背景・PiP・同一シリーズ移動・画質変更で維持し、新しいアカウントのキューと混在させない。
- 作品を切り替える直前に既存APIで最新の所属・権限を確認。削除やシリーズ移動・キャンセル時は古い候補を勝手に再生しない。オフラインの単体リピートは期限内に利用可能。シリーズ移動は現在の仕様どおりサーバー接続が必要で、接続できなければその場で停止して案内する（保存データを削除しない）。
- 連続再生をオフにすると自動リピート／次への移動を停止。リピート／シャッフルを新たに選ぶと連続再生を有効にする。手動の前後移動は連続再生オフでも可能。
- 表紙から96点を疑似ランダム抽出して、色のある3色を選び、現在の暗い背景へ静的な放射状の光を重ねる。作品IDから種を作るため、毎秒の描画で色がちらつかない。グレー画像・表紙なしは既定色へフォールバック。画像・解析結果を外部へ送信しない。
- AndroidはWebViewだけでなく、safe-area／ネイティブpaddingの外側のWindowとDecorViewも現在のテーマ色にする。Capacitorの標準insets処理は変更せず、キーボード・ノッチ処理を二重化しない。テーマ再選択／復帰／回転でもバーの文字色を同期する。[Android公式](https://developer.android.com/develop/ui/views/layout/edge-to-edge)の透明なシステムバーと背面描画の扱い、および導入済みCapacitor SystemBars実装を確認した。
- ドロワーは参考動画のX型。指に沿って一覧も押し出し、直近120msの速度と半分の開閉位置で離した後の行き先を決める。途中の逆向きフリックも反映。縦スクロール・複数指・キャンセル・入力欄は従来どおり保護し、動きを減らす設定では補間アニメーションを省く。
