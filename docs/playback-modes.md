# リピート・シャッフル・再生背景

> このページは旧リンクからの案内です。Mirea `1.0.0`の手順は、以下の利用者ガイドにまとめています。公開版ごとの変更は[リリース履歴](../RELEASE.md)を参照してください。

動画・音楽には「リピートなし」「単体リピート」「シリーズ／リストのリピート」とシャッフルがあります。シリーズやプレイリストから開いた場合は、その再生単位を使います。

- 単体リピートは現在の作品を先頭から再生します。
- シリーズ／リストのリピートは対象の最後から先頭へ戻ります。
- シャッフルは候補を一巡するまで重複を避け、前の作品へ戻る操作は実際の再生履歴を使います。
- 連続再生をオフにすると自動の次移動・繰り返しを止めます。手動の前後移動は使えます。

どのモードでも、作品の権限や端末保存の期限を越えて再生することはできません。通信できない場所で続けて再生したい場合は、次の候補も保存しておきます。

音楽の背景は表紙から選んだ色を使います。再生停止・プレイヤー非表示・動きを減らす設定などでは動きを抑えます。元の表紙や作品データは変更しません。
