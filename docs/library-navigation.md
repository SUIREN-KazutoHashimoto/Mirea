# 一覧・メニュー・背景再生（0.7.1beta）

- APKは画面幅にかかわらず左側ドロワー、Webは760px以下でドロワー、それより広いPC画面は常設サイドバー。
- 右へスワイプすると、幅に対する移動距離に応じてメニューと背景の暗さが連続的に変わる。離すと半分以上なら開き、半分未満なら戻る（24px以上の速いフリックは方向を優先）。指を動かしている間は追従を遅らせるtransitionを使わない。縦スクロール・複数指・キャンセル時は元の開閉状態へ戻す。左スワイプ・背景タップ・Esc・アプリの戻るで閉じる。メニューボタンでも開閉可能。入力欄・複数指・縦スクロール・本／動画の操作は横取りしない。
- 閉じたメニューはinertでフォーカス不可。開いた間は背後をinertにしてTabをメニュー内へ閉じ込め、閉じたらフォーカスとスクロールを戻す。
- コンテンツ／シリーズの追加はコンパクト表示のメニュー内へ移動。同じDOMノードなのでPC幅へ戻しても操作状態・権限は維持する。処理中の件数や送信待ち通知もメニューから確認できる。
- カードからダウンロード・削除・「…」ボタンを撤去。アセットは500ms長押し、右クリック、またはShift+F10／ContextMenuキーで簡易メニュー（暗号化ダウンロード／端末保存の解除／サーバーから削除／詳細）を表示する。詳細は従来の情報ポップアップへ進む。端末保存の解除も確認画面を経由し、サーバーの作品や記録は消さない。移動・スクロール・複数指・キャンセル・非表示では長押しを取り消す。長押し終了時のクリックで勝手に再生しない。
- 詳細は自分にアクセス権のある一覧情報のみ。削除や字幕編集は編集権限がある場合のみ。削除は従来の確認画面を経由し、サーバー側のACLも変えない。
- 一括DLは選択した本棚・検索・種別・シリーズの一覧結果を開始時に固定する。画面内に見えている数枚だけではなく、下へスクロールした結果も対象。処理中・重複は除外、保存済みはスキップ。直列で既存の暗号化取得処理を利用する。失敗は作品別に表示し、認証喪失・容量不足・中断では以降を止める。完了前の暗号化チャンクは削除しない。動画は通常の保存時の初期画質を使い、既存保存の画質は変更しない。
- 音声の「戻る／閉じる」は画面を閉じるだけで再生継続。動画はPiPへ移り、ライブラリを前面へ戻す。PiP非対応・拒否は背景音声へフォールバック。停止はミニプレイヤー・通知・再生オプションの「再生を終了」で明示的に実行する。
- [Android公式PiPガイド](https://developer.android.com/develop/ui/views/picture-in-picture)に従い、再生Activityは非公開のsingleTaskとして単一再生を維持。専用タスクでライブラリと同時表示し、戻る操作でService／プレイヤー／続き位置を作り直さない。システムのPiPウィンドウ自体を閉じる場合は再生を終了する。
- 右下のサムネイル型ドックをWeb／APK共通で使用。サムネイルでプレイヤーへ復帰、再生／一時停止・停止ボタン、右矢印で折り畳んで左矢印だけにする。折り畳みは再生を止めない。アセット・アカウント・接続先が変わる場合は古い表紙URLと取得を破棄する。Webは同じタブのミニプレイヤーを維持。PiPの可否はブラウザーに従い、タブを閉じた後の再生やOSによる強制終了後の継続は保証しない。ログアウト・権限喪失・視聴期限切れは従来通り停止。
- アプリだけメニュー・ポップアップ・手動の一覧切替・ボタン押下に短い動きを付ける。常時動く装飾は使わず、prefers-reduced-motionでは無効化。定期ポーリングでの一覧再描画はアニメーションさせない。

- Androidの既存MediaStyle通知にsetLargeIconを付け、MediaSessionのART／ALBUM_ART／DISPLAY_ICONへ同じBitmapを渡す。表紙は認証済み取得／暗号化DLの端末画像をメモリー内で512px以下に縮小する。公開画像URLやトークン付きURLをOSへ渡さない。シリーズ遷移時に前のアセットの表紙を引き継がない。表示位置・背景の描画はOS側に依存する。[Android MediaStyle](https://developer.android.com/reference/android/app/Notification.MediaStyle)・[MediaMetadata](https://developer.android.com/reference/android/media/MediaMetadata)参照。
