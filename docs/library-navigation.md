# ライブラリの移動と表示

> このページは旧リンクからの案内です。Mirea `1.0.0`の手順は、以下の利用者ガイドにまとめています。公開版ごとの変更は[リリース履歴](../RELEASE.md)を参照してください。

PCの広い画面では左のサイドバー、狭い画面やAndroidアプリではメニューボタンから本棚・設定などを開きます。横スワイプでメニューを引き出す操作は使いません。

シリーズを開くと、その直下の作品と子シリーズを表示します。戻る操作で上の階層へ戻れます。Androidの最上位一覧で戻る操作をするとメニューを開きます。

一覧の表示形式は2列・3列・5列・リスト、表示情報は詳細・サムネイル＋タイトルです。定期更新に加え、更新ボタンやタッチ画面の下方向への引っぱりでも再取得できます。同じ内容なら一覧表示を維持します。

作品を開くときはクリック・タップ、操作メニューは右クリック・長押しです。PCのキーボードでは作品へフォーカスしてShift+F10を使えます。
