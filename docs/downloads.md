# 作品を端末へ保存する

> このページは旧リンクからの案内です。Mirea `1.0.0`の手順は、以下の利用者ガイドにまとめています。公開版ごとの変更は[リリース履歴](../RELEASE.md)を参照してください。

Mireaには、一覧を表示するための「一覧・表紙の保存」と、本体を読むための「暗号化ダウンロード」があります。一覧に作品が見えても、本体の保存が完了しているとは限りません。

| 操作 | 保存するもの |
| --- | --- |
| 設定から「全アセットの一覧・表紙を保存」 | 本棚・シリーズなどの情報、作品名、表紙 |
| 作品の「暗号化ダウンロード」 | その端末で閲覧するための暗号化された本体 |
| 一覧の一括ダウンロード | 開いている一覧の条件に合う、保存可能な作品の本体 |

保存済み作品は、有効な閲覧許可の範囲で最後の成功した権限確認から最大7日間利用できます。ログインの保持期間30日とは別です。再接続して権限確認が成功すると期限を更新します。通信ができないまま永久に延長する仕組みではありません。

「端末から削除」はサーバーの作品を残します。ログアウト、アプリの削除、サイトデータの消去は保存データや許可に影響するため、不要な再インストールから試さないでください。
