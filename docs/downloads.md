# 期限付きオフライン・暗号化ダウンロード（0.6.0beta）

動画・音声・PDF・EPUB・画像の本を、アカウント／サーバー別に暗号化保存します。事前にダウンロードを完了すれば、最後にサーバーがその作品のアクセス権を確認した時点から最長7日間、通信なしで起動・閲覧・再生できます。ログイン期限が先に来る場合は短い方が上限です。ログイン自体は新規ログインから最長30日で、期限は自動延長しません。旧ログインの期限は遡及延長しないため、一度ログインし直すと30日になります。

## 起動時の接続判定（0.10.0beta）

起動の認証・設定・一覧取得には共通で約1.2秒の通信期限を設けます。圏外判定時は通信せず、到達不能／応答停滞時は期限内で保存済み一覧へ切り替えます。Webは保存済み静的資材を優先し、画面のネットワーク待ちは約0.9秒までです。これは通信待ちの上限であり、端末のディスク読み込みやOS起動時間は含みません。

有効な7日間の認可がある作品だけを従来の検証で開き、接続失敗で期限を延長しません。401等の明示的な拒否はオフラインへの逃げ道にしません。Androidの保存済み再生もオフライン時の進捗照会・サムネイル取得・再認可待ちを省き、暗号化された既存許可／進捗を使います。再接続の自動同期と失効処理は維持します。

## 利用と自動同期

- カードの「暗号化ダウンロード」で全分割と閲覧許可を保存します。設定の「端末のダウンロード」でも開けます。保存領域維持を要求しますが、OS／ブラウザーの回収を完全には防げません。
- Webは同じHTTPS URLで開きます。画面コード・PDF用資材だけをService Workerへ事前保存し、オフライン起動時は保存済み作品の一覧を表示します。APKは同梱画面を使用します。動画・音声はネイティブ再生、本は暗号化Range経由のリーダーです。
- 起動・オンライン復帰・画面復帰・30秒間隔で、操作不要の再接続を試みます。サーバーで認証できたら各作品の権限・原本を照合し、7日期限を更新します。更新された作品は再ダウンロードします。未送信の閲覧記録・続き位置も再送します。接続失敗では期限を延長しません。ブラウザー／アプリ終了中やOSによる停止中は実行できず、次の起動／復帰時に再開します。
- 権限取り消し・アカウント停止・セッション失効・作品削除を確認した場合は許可を破棄し、開いている作品も停止します。通信のない端末への即時失効通知はできず、再接続または残り期限の満了までが上限です。
- ログアウト時は閲覧許可を無効化します。暗号化メディアは保持しますが再ログイン・再認可が必要です。オフラインのブラウザーログアウトはローカル復元を禁止し、接続復帰時に残ったCookieも失効処理します。
- 既存の暗号化ダウンロードは、更新後にオンラインで一度開くか自動同期を待つと許可を取得します。旧APKは従来動作なので、新APKへ上書き更新してください。

## 暗号・期限

メディアは1 MiB単位のAES-256-GCM、ランダム96-bit IV、128-bitタグで暗号化します。AADに登録ID・ファイル番号・分割番号・平文長を含め、長さとSHA-256も検証します。動画全体を平文ファイルへ展開せず、Range／HEAD／シークに必要な分割だけメモリー内で復号します。各種本の表示内容もリーダーのメモリーには存在します。

WebのIndexedDB v2は既存packages／chunksを保持してvaultを追加します。復号鍵・許可・本人プロフィールは端末／origin／アカウント別の非抽出Web Crypto AES-GCM鍵で暗号化します。保護用CryptoKeyは非抽出のままIndexedDBへ保存し、平文の復号鍵・パスワード・永続Bearerトークンは保存しません。永続ログインはSecure／HttpOnly／SameSite=Strict Cookieのままです。作品タイトル・種別・サイズ等の管理メタデータは従来どおり平文です。

Androidのネイティブ動画／音声用の許可は専用Android Keystore AES-256-GCM鍵で保護し、ログイン鍵・APK署名鍵・更新署名鍵から分離します。アカウント／origin別パーティションは不変です。本のWebViewにも平文メディア／平文復号鍵を保存しません。

期限はサーバー時刻を起点とし、端末の経過時間で判定します。時計の巻き戻しはオンライン再確認を要求し、稼働中は単調増加時計でも制限します。各Range／分割で期限を検査し、開いたままの本も定期検査で閉じます。

これは保存データ保護でありハードウェアDRMではありません。端末を支配する攻撃者による時計／保存領域の巻き戻し、改造アプリ、XSS、開発ツール、root、メモリーダンプ、画面録画、復号済みデコーダーのバッファの遠隔回収までは保証しません。HTTPSと証明書検証は必須です。

## 履歴と続き位置

詳細イベントは元のID・view・seq・時刻を保持し、同じアカウント／サーバーへ再送します。件数・経過日数だけで未送信ログを捨てません。不正イベント・権限喪失による拒否、容量不足、サイトデータ削除等では欠測し得ます。サーバーの生ログは無期限保存、管理者向け匿名集計の条件も不変です。続き位置は更新ID／revisionで競合を検出し、別端末の新しい位置を黙って巻き戻しません。

## API・運用

| /api/v1からのパス | 内容 |
| --- | --- |
| POST /items/:id/download | 現在の認証・所属を検査、登録とmanifestを返す。鍵なし |
| GET /downloads/:id/files/:file/parts/:part | 現在ACLで暗号文を取得。期限更新なし |
| POST /downloads/:id/open | 現在の認証・所属・原本を再検査。manifest・userId・key・serverTime・expiresAt。no-store。期限=min(セッション期限,serverTime+7日) |

1作品8 GiB、画像本500ページまで。1作品1画質、動画はH.264/AAC MP4から選択。端末容量・機能制限は従来どおり。API／メディアをCache Storageへ平文保存しません。画面の事前キャッシュはビルド時に固定した同一originのコード・PDF用資材だけです。

サーバーのDATA_DIR/keys/download-master.keyと既存のHKDF導出を変更しません。既存登録があるのに鍵がなければ起動拒否します。DATA_DIR全体（DB・鍵）と設定を同時点でバックアップしてください。APKは従来の専用署名で更新し、アンインストール不要です。
