# 続き位置と閲覧履歴

> このページは旧リンクからの案内です。Mirea `1.0.0`の手順は、以下の利用者ガイドにまとめています。公開版ごとの変更は[リリース履歴](../RELEASE.md)を参照してください。

同じサーバー・アカウントでは、PCとAndroidの間で保存済みの続き位置を引き継げます。「最も遠くまで進んだ位置」ではなく、最後に保存した再生・閲覧位置です。プレビューの視聴は本編の続き位置を変更しません。

動画・音楽は再生時刻、本はページや表示位置を復元します。EPUBは端末や文字サイズでページ割りが変わるため、同じ文字の位置に厳密に一致するとは限りません。

通信できない間は保存を保留し、接続時に送ります。別端末で同時に進めた場合、古い端末の遅れた更新で新しい位置を黙って上書きしないよう競合を扱います。端末を切り替える前に一時停止して同期すると確実です。OSの強制終了や電源断の直前の位置まで保存できる保証はありません。

「最初から」は再開位置を戻す操作、「閲覧履歴から非表示」は履歴画面の整理です。どちらも過去の詳細記録を全削除する操作ではありません。
