# 複数の作品をまとめて追加する

> このページは旧リンクからの案内です。Mirea `1.0.0`の手順は、以下の利用者ガイドにまとめています。公開版ごとの変更は[リリース履歴](../RELEASE.md)を参照してください。

「コンテンツを追加」で本棚とシリーズを指定し、ファイルを複数選びます。PCのWeb/PWAではライブラリへのドロップでも選択画面を開けます。この時点では送信しません。

通常のファイル選択ではPDF・EPUB・動画・音声がそれぞれ一作品になります。JPEG・PNG・WebPを複数選んだ場合は一冊の画像本としてページを確認します。フォルダ取り込みはフォルダをシリーズ、ファイルを作品として扱うため、画像のまとまり方が異なります。

一度の選択は最大1,000ファイルです。Mirea 1.0.0では追加前に内容・重複を確認してから送信します。送信を始めた後も追加画面を閉じて別の操作を続けられます。タブ・アプリを終了してよいかは、転送状況で未送信ファイルが残っていないか確認してください。

シリーズのカードを開くと、その中の作品へ進めます。通信できない場合でも、事前保存した一覧・表紙からシリーズ構成を表示できます。作品本体の閲覧には別途ダウンロードが必要です。
