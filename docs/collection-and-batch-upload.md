# シリーズカードと複数アップロード（0.9.0beta）

- Web／アプリの通常一覧は、シリーズ所属アセットをシリーズIDごとに1カードへ集約。同名でも別シリーズは混ざらない。表紙は先頭作品、件数と本人の閲覧済み件数を表示する。
- カードを開くとシリーズの設定順で個別作品を表示し、「一覧に戻る」で元の検索・種類・並び順に復帰。空のシリーズもカードを表示し、編集権限があれば中から作品を追加できる。空のシリーズは種類別フィルターには出さない。
- 検索・種類フィルターは従来どおりアセットに適用。一致したシリーズは1カードで「一致数／全作品数」を示す。表紙・件数は現在の本棚権限で見える情報だけを使う。アクセス権の新規付与や閲覧ログの追加はしない。
- 「表示中を一括DL」はカード内の該当アセットを展開して対象にする。空のシリーズ、処理中アセットは含めない。端末オフライン一覧は従来どおり保存済みのアセットを表示し、未保存のシリーズ情報を推測・追加しない。
- アップロードは複数のPDF／EPUB／動画／音声を同時選択できる。ファイルごとに1アセット。JPEG／PNG／WebPは数値順で1冊にまとめ、ページの並べ替え／除外が可能。画像と他の種類を混在選択でき、アセットごとにタイトルを編集できる。
- 最大3件を並行して送信・後処理。既存セッションを考慮して並行数を調整し、残りはブラウザー内で順番待ち。既存のサーバー側3セッション上限・分割サイズ・SHA256検証・権限確認を変更しない。サーバー上限429や認証／権限エラーでは新規開始を停止し、利用者へ再試行を案内する。
- 1アセットのサイズ・画像1枚・ページ数・EPUB上限を個別に検証。バッチ全体を1アセットのサイズ上限で制限しない。一度に100アセットまで。同名・同サイズ・同更新日時の非画像ファイルの重複選択は、再開IDの競合を防ぐため拒否する。
- 送信と後処理の状態・失敗をアセット別に表示。通常の個別エラーでは他の転送を続行し、再試行は完了済みを除外する。送信後のタイトル等を固定して二重登録を防ぎ、選び直す場合は明示操作とする。原本保持は引き続き初期ON。
- 画面を閉じる／中止すると、未送信分は開始せず、送信中は従来どおり取り消し、サーバー後処理中は監視だけを切り離して継続する。端末のファイルを永続保存してバックグラウンド転送する機能ではない。再開は同じファイルを再選択する。サーバーの完了済みアセットはキャンセルで削除しない。
- アカウント／接続先変更、遅れて届いた進捗、閉じた画面へのコールバックでは次の転送を始めない。ファイル・資格情報はログや外部サービスへ送らない。
