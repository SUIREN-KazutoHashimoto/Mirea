## 保存構造と不変条件

AI表は既存のアセットIDと本棚に従属します。アセット削除は結果・単位・訂正・タグ・索引・ジョブを外部キーで連鎖削除します。管理者のメディアリセットでは、個人検索条件、一括依頼、冪等要求も削除し、導入済みモデルとサーバー設定は保持します。

- `ai_results` はアセット×機能の公開中の世代と軽量な集計を持つ。
- `ai_result_units` はページ・章・90秒区間ごとの原結果を持つ。巨大な一括JSONを通常の読込単位にしない。
- `ai_result_locations` は領域IDから元単位への対応を持ち、訂正時に全文を走査しない。
- `ai_edits` は領域ごとの現在の手動差分、`ai_edit_history` は操作番号・更新版・履歴を持つ。
- `asset_tags` は共有と本人専用を分離する。手動採用・却下を再解析で消さない。
- `ai_documents` とFTS5 trigramは有効な訂正を適用した文字と位置を持つ。ベクトルはモデルIDで空間を区別する。
- `ai_models` は固定revision、ファイル一覧、検証値、確認者・日時を持つ。重みはDBに入れない。
- `ai_jobs` と `ai_units` は永続要求と成功・失敗のチェックポイントを持つ。
- `ai_batches` と `ai_batch_assets` は受理時の対象を固定し、毎秒10件ずつ個別要求へ展開する。

原本と確認済みモデルは保持し、一時ファイルは `DATA_DIR/ai/work`、別途取得モデルは `DATA_DIR/ai/models` に置きます。AIの待機・実行・一時停止中は必要なメディア原本を回収しません。通常の完全バックアップにはモデルファイルも含め、一時処理ファイルは含めません。メタデータのみのバックアップから戻す場合はモデルファイルも別途復元・再導入します。

## 解析パイプライン

### 書籍

EPUBは検証済みの本文ツリーを1800文字単位へ分け、章・要素パス・文字オフセットを保存します。PDFはpdf.jsで文字・座標と画像の有無を調べます。画像を含まない文字PDFは埋め込み文字を使い、混在ページは元の文字と画像OCRを合わせます。

画像は回転を適用し、長辺2800の概観と必要な1600pxタイルを生成します。タイルには128pxの重複を設け、同じ文字を近接座標で重複除去します。画像PDFも高解像度のラスタライズ後にタイル処理します。原画像を書き換えません。極端に大きなページでは256タイルの解析上限で安全な未解析状態にし、既存のアップロード受入条件を変えません。

結果は原文、種別、読む順序、1始まりのページ、正規化矩形、またはEPUB内の安定位置を持ちます。領域IDは文字・位置等の指紋を含め、順番が同じという理由だけで旧訂正を別の文字へ適用しません。

### 音声と動画

文字起こしは90秒ずつモノラル16kHzへ変換し、Whisperの相対時刻を原音源の整数ミリ秒へ戻します。動画は同じ区間で場面変化を検出し、場面直後・先頭・末尾・補助位置から最大6枚を選びます。正確な抽出時刻と対応する発話を視覚モデルへ渡し、固定秒数だけの章名を作る指示にはしません。

音楽の構成はHTDemucsで4音源へ分け、81帯域の対数スペクトログラムをAll-In-Oneの8 foldへ入力して合議します。全曲の構造を扱います。CPU用近傍注意は局所窓の演算で、全時刻間の巨大な行列を作りません。境界近傍の極端に短い区間と同一ラベルの隣接区間を整理します。実曲のジャンルごとの品質評価と、合成音による実行確認は区別します。

タグはページ・時間区間の画像、抽出文字、発話、利用可能な曲構成を根拠に保存します。実在人物の同定や機微な個人属性の推定は指示しません。モデルの生スコアを校正済みの確率として表示しません。

### ジョブと資源

通常のサムネイル・トランスコード等とは独立した待機列です。AIの初期値は無効、CPU、同時1、最大4スレッドです。モデル用メモリー予算、常駐数、文脈・出力、起動待ち、未使用解放、一時容量、実行時間帯を設定できます。

実行枠は1ページ・1時間区間ごとに返し、利用者と古い待機時刻を考慮して選びます。閲覧・転送要求を受けた直後は新しい解析を遅らせます。ネイティブ推論・FFmpegは通常より低いCPU優先度で起動します。音楽・音声認識の予約とLLM常駐モデルの予約を合算します。

開始前、単位保存前、公開前に現在のアカウント・本棚権限を検査します。権限喪失や取消では子処理を中断し、未承認の結果を公開しません。再起動時の実行中は待機へ戻り、DBに成功済みの単位を使います。失敗分だけの再試行では成功した単位を残します。

元情報とモデル・解析設定の指紋で同じ待機要求の重複を抑止します。入力世代が変わったらチェックポイントを作り直し、より新しい完了結果を古い要求が上書きしません。モデル準備、依存する解析、メモリー、一時容量は破損と区別して待機に置きます。

## 手動訂正と検索

訂正は結果版と編集版の両方を要求し、古い画面からの保存は409で再確認します。同じ操作番号の再送は冪等です。文字、名称、時刻、領域、読む順序、非表示、区間の分割を別の差分として保持します。結合は境界の変更と不要区間の非表示、または手動分割群の統合で表現します。

再解析後も対応するIDへ訂正を適用します。対応しないものは確認待ちの旧訂正として残し、誤った場所へ移しません。確認済み操作は現在の差分から外しますが、履歴を残します。差分の再索引は変更した単位だけです。FTSの外部コンテンツと派生区間の削除も整合させます。

検索ワーカーは現在のmembershipをSQLで絞り、本棚・子シリーズ・本人のプレイリスト・種類・共有/個人タグを適用します。通常の横断検索はプライベート本棚を除外し、明示した本棚では追加認証を要求します。ワーカー結果を返す直前にも現在の権限を再検査します。

意味検索は最大4要求のローカル埋め込み生成を持ち、短時間の本人別キャッシュを使います。最初の700msで準備できなければ文字列検索を返します。後から得た候補は利用者が選んで表示し、既存の行を自動で並べ替えません。ベクトルの比較はワーカー内の時間予算で打ち切るため、非常に大きい索引での全件厳密近傍保証とは区別します。

## 再生・端末保存・権限

検索で指定した位置は通常レジュームより優先し、連続再生の次作品へ引き継ぎません。AIの公開だけでメディアソース・音量・再生速度・キューを作り直しません。A–Bリピートは選択時の境界と期限を保持し、解析の更新では動かしません。

Web/PWAの解析パックは本人・サーバー別の既存AES-GCM vaultで保存します。チェックサム、結果版、編集版、入力世代を照合し、異なる世代のページを混ぜません。ページ単位の同期は再開・再利用でき、曲の区間はAndroidのKeystore側にも保存します。

最長7日の許可、単調時計、時計巻き戻し、ログアウト、現在の目録と本棚解除を適用します。確認できた401/403/404/423を通信障害のキャッシュフォールバックとして扱いません。解析パックはメディア本体の閲覧許可の代わりにはなりません。

## 実行コードと外部通信

推論子プロセスにはサーバーの秘密環境変数を引き継ぎません。llama-serverはループバックとランダムなAPI鍵だけを使います。Linuxは非特権seccompランチャーで外向きconnect、宛先指定sendto等を拒否します。既存のコンテナ制限を緩和しません。音楽アダプターはweights-only読込と固定アーキテクチャを使い、Pythonの外向き接続も拒否します。

取得処理だけが公式HTTPS配布元の限定リストへ接続します。固定revisionと容量・SHA-256を照合し、別originへのリダイレクトでは認証ヘッダーを引き継ぎません。モデル専用の任意Pythonコードは実行しません。

## 検証

`pnpm test:ai` は合成DBによる認可・非公開範囲、冪等・再起動・一部失敗、1000件を超える対象、モデル取得の中断再開、ページ世代、暗号化期限、訂正とFTS整合を検査します。`scripts/check-ai-ui.mjs` は専用のループバックサービスとブラウザーでPC/スマートフォン幅を操作します。

CPUでは固定版実モデルを使う合成画像OCR、文字起こし、1024次元の埋め込み、音楽構成の実行を確認します。ビルド・単体検査・合成資料の成功と、Android実端末、Vulkan実GPU、作品全般の認識精度は区別します。

### 失効と同期の競合

Webの保存レコードは暗号化された失効世代を伴います。ネットワーク要求の開始前に世代を取得し、既知の拒否では世代を更新します。保存後の読込でも照合するため、拒否と暗号文公開が競合しても古い応答を再表示しません。Androidもアセット失効世代とアカウント消去世代を照合し、Webからの保存依頼はネイティブ側で改めて認可付き取得を行います。

本体保存後に解析情報の取得を別処理で開始します。通常本棚の保存済み作品は目録更新時に最大8件を順次補充し、同じ作品の確認は原則5分間隔です。プライベート本棚は無操作で認証を求めず、明示した保存操作で更新します。ページ取得は最大8パック・約4MiBをまとめ、途中の世代変更では再取得します。辞書・タグ・本文の全件を通常の目録へ混入させません。

実行可能なジョブの取得時には、依存待ちをSQLで除外します。先頭100件が依存待ちでも、後ろの実行可能な要求を止めません。自動登録の走査もキーページングし、準備できない一部の作品だけで全走査が止まることを防ぎます。

## CPU長時間処理と訂正履歴

視覚モデルのCPU推論は5分を超える場合があります。ローカル推論HTTPは `127.0.0.1` の限定エンドポイントだけへ接続し、1時間の総期限、応答容量、取消を明示します。応答ヘッダー待ちだけの短い既定期限で正常な解析を打ち切りません。取消・失敗では子プロセス終了を待ってから実行枠とメモリー予約を返します。

手動訂正の履歴は編集権限を検査して分割取得し、指定した編集版を新しい版として復元します。復元要求も結果版・編集版・操作IDを照合します。区間の分割・結合で作った検索行を入れ替え、古い派生行を残しません。履歴を戻す操作で原結果やメディア原本を変更しません。

長い認識文字は全文一致用の行を保持したうえで、1800文字・200文字重複の埋め込み用断片へ分けます。断片の位置は元領域へ対応させ、検索表示で同じ領域を重複させません。検索文字はNFKC、英字大小、片仮名・平仮名を正規化します。

端末の既存の非抽出型暗号鍵はそのまま利用します。新しく作る鍵レコードには世代を持たせ、ログアウト前に始まった遅い保存処理を、再ログイン後の解析情報として利用できないようにします。メディアの暗号鍵を移行や再生成の対象にしません。

### 合成資料で確認した範囲

CPUの実モデルで、日本語の横書き・縦書き・吹き出しを含む画像のOCR、タグ、埋め込み索引の一連の公開を確認しました。2つの話題を持つ合成動画では、映像と時刻付き発話から対応する章境界を保存しました。Whisperの文字起こし、HTDemucsとAll-In-Oneの曲全体処理も別の合成資料で実行しています。

これは実行経路の検証であり、作品全般の認識精度評価ではありません。日本語のOCRにも誤認識があるため、原情報・範囲・訂正機能を提供します。Vulkanを指定したCPU専用環境ではCPUへ戻ることを確認しましたが、実GPU性能やGPU固有の動作は未確認です。Linuxコンテナのビルド・通信制限検証は正式CIの別項目とし、Windows上の成功から推定しません。

モデル退避中のメモリーと参照も、子プロセスの `close` まで予約に含めます。退避を待つ間に別要求が同じモデルを起動した場合は、その起動中・常駐インスタンスを再確認して使います。モデルの二重起動と終了前の過剰予約を、終了タイミングを制御する合成エンジンで検査しています。

シークバーの解析境界は最大250本に間引いて描画し、区間一覧の件数とは分けます。既存の手動動画章があれば、その境界を優先します。次のサビへの移動は現在位置より後の最も近いサビを選び、末尾では先頭へ戻ります。範囲の微調整は現在の作品・閲覧許可・再生時間を検査し、選んだ範囲は解析の更新で動かしません。長時間開いた画面でも、解析情報の単調時計の期限を延ばさず、期限切れの表示と操作を終了します。

認証はリクエストの入口に加え、本文を受信した後のハンドラー直前にも再確認します。入口の認証後にログアウト・失効したタグ編集等を、そのまま保存することを防ぎます。非同期処理の公開・応答時の認可確認とは別の検査です。

## 採用範囲と追加提案

中核は、全種類の手動・自動タグ、書籍の文字認識、曲の構成、動画の章、文字列・意味検索、訂正と履歴、永続ジョブ、保存済み作品の解析情報です。追加提案では次の範囲を実装しています。

| 提案 | 現在の実装 | 追加の検討範囲 |
| --- | --- | --- |
| 時刻付き文字起こし | 音声・動画の90秒区間と元時刻への対応 | 話者分離、歌唱専用の品質評価 |
| 関連作品 | 現在の権限内の共通タグと理由表示 | 作品間ベクトルの関連箇所提案 |
| スマートリスト | 本人の検索条件保存・更新・削除と同じ一覧での表示 | 固定キューを作る専用の連続再生、検索結果の一括コピー |
| 書き出し | アセット単位の全結果・現在の手動訂正のストリームJSON | 一括配布形式や他製品への専用変換 |
| ネタバレ制御 | 検索抜粋を既定で隠し、操作時に表示 | 本人・作品・シリーズ別の永続した上書き設定 |
| 確認一覧 | 失敗・一部未解析ジョブ、非表示の箇所、対応が変わった訂正 | 人の正解資料で校正した信頼度による横断レビュー |

分野・言語ごとの品質測定、実作品全般の精度保証、Android実端末、Vulkan実GPU、Linuxコンテナの実行結果は、それぞれ別の検証項目です。合成資料の実行成功だけで、これらを完了扱いにしません。
