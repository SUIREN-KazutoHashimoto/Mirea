# 音声・音楽を追加して聴く

> このページは旧リンクからの案内です。Mirea `1.0.0`の手順は、以下の利用者ガイドにまとめています。公開版ごとの変更は[リリース履歴](../RELEASE.md)を参照してください。

MP3、M4A/M4B、AAC、WAV、FLAC、Ogg/Vorbis、Opus、AIFF、WMA、音声WebMなどを音声アセットとして扱います。拡張子だけでなく実際の内容を検査します。DRM付きのファイルは対象外です。

1. 「コンテンツを追加」で本棚・シリーズを指定し、音声ファイルを選びます。
2. 必要に応じてタイトルと原本保持の設定を確認して送信します。
3. 受信後、サーバーが表紙や再生用データを準備します。
4. 一覧から開いて再生します。原本で再生できるかは、元の形式と端末の対応にもよります。

配信用にはAAC/M4Aへの変換を行います。ロスレス・ビットパーフェクト再生を保証する設計ではありません。原本保持をオンにしても、常に原本が選ばれるわけではありません。

埋め込みジャケットから表紙を作り、利用できない場合は既定の表紙を使います。カスタム表紙への変更も可能です。保存済み作品、バックグラウンド再生、シリーズ・プレイリスト内の連続再生、イコライザーを利用できます。
