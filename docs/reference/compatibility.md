# 対応形式と機能の範囲

対象は[現在のチェックアウト](../status.md)です。OSやブラウザーの機能が必要な操作は、その条件も満たす必要があります。

## コンテンツ

| 種類 | 入力 | 閲覧方法と主な制限 |
| --- | --- | --- |
| PDF | PDF | PDF.js。暗号化/破損PDFは拒否。ページ・倍率・続き位置 |
| 画像の本 | 静止JPEG・PNG・WebP | 1〜1000枚を1冊。1枚100 MiB以内、合計はサーバー上限。原画像保持 |
| EPUB | DRMなしのリフロー型EPUB 2/3 | 目次・文字サイズ・続き位置。固定レイアウト・スクリプト・原HTML/CSSそのままの表示は対象外 |
| 動画 | MP4/M4V、MOV、MKV、WebM、AVI、WMV/ASF、MPEG、TS/MTS/M2TS、FLV | 内容をFFprobe等で検証。H.264/AACの配信データを生成。原本の直接再生は端末codec次第 |
| 音声 | MP3、M4A/M4B、AAC、WAV、FLAC、OGG/OGA/Opus、AIFF、WMA、WebA | 内容検証後AAC/M4Aを生成。原本保持の選択が可能 |

拡張子が合っていても、内容・codec・暗号化・破損の検証で受け付けられない場合があります。動画・音声の原本保持は既定ONです。本の原本は保持します。カスタム表紙も原本を残し、表示用WebPを生成します。

画像の画素数上限はありませんが、画像を展開するメモリー、処理時間、同時数の制約はあります。100 MiB以下なら必ず処理できるという意味ではありません。

EPUBには独立の保護上限があります。原本64 MiB、ZIP展開合計48 MiB、閲覧bundle32 MiBなどを検証します。アセット全体の上限を増やしても解除されません。ZIP/CBZ/CBRを画像本として直接取り込む機能、MOBI/AZW、DRM解除はありません。

形式の正本: [video-types.js](../../server/video-types.js)、[audio-types.js](../../server/audio-types.js)、[ebook-types.js](../../server/ebook-types.js)。

## クライアント

| 機能 | PC Web/PWA | Androidアプリ |
| --- | --- | --- |
| ライブラリ・本棚・シリーズ | 共通UI | 同梱Web UI |
| 本の閲覧 | ブラウザー内ビューアー | WebView内ビューアー |
| 動画・音声 | HTML media/HLS | Media3によるnative再生 |
| バックグラウンド再生 | ブラウザー/OSの制約あり | 独立した再生サービス・通知操作 |
| PiP | ブラウザー対応時 | OSのPiPと再生Activity |
| ファイル送信 | 開いたページから継続。閉じると継続保証なし | foreground転送サービス |
| 暗号化保存 | IndexedDB等、ブラウザー容量・消去方針の影響 | Web保存とnative暗号文キャッシュの連携 |
| プライベート本棚 | パスワード確認 | 登録済み生体認証、利用不可/失敗時はパスワード |
| APK自動更新 | 対象外 | 署名情報を検証しOS条件に応じて適用/確認 |
| PWAインストール | ブラウザーが対応する場合 | APKとは別アプリとして扱う |

PWAとAPKは別の保存領域です。PWAで保存した作品がAPKへ自動で全コピーされるとは限りません。サーバーに同期した進行度などと、端末にしかない本体データを区別します。

AndroidのminSdkは29（Android 10）、compile/targetは36です。最低OS条件と、全端末で検証済みであることは別です。Android System WebViewも更新してください。iOSの専用nativeアプリは提供していません。Web/PWAとして使う場合も、そのOS・ブラウザーの保存や再生制限を受けます。

## サーバー

| 方式 | 条件 |
| --- | --- |
| Linuxコンテナ | 公開イメージはlinux/amd64。Landlock ABI 3以上等の起動検査に合格すること |
| Docker Desktop | Linuxコンテナ/VM側の上記条件が必要。OS名だけでは対応を断定しない |
| TrueNAS Custom App | DockerベースAppsを使う基盤の例。対応版・設定は[専用手順](../install/truenas.md) |
| Node.js直接起動 | Node24.13以上の24.x、依存とメディア処理バイナリ。Windows/Linuxの手順あり |
| 複数サーバー/水平分散 | 同じSQLiteを複数インスタンスで共有する運用は対象外 |
| GPU変換 | 現行の標準配布構成にはGPUトランスコード設定なし |

DBをSMB/NFSで複数ホスト共有しません。DBと大容量メディアを分離する場合は[保存先](../storage.md)を参照してください。利用可能な最大作品数・同時利用者数・実効速度は、入力形式と資源によって異なるため保証値を置いていません。

## 保存期限と認証

ログイン保持は最長30日を基本とし、ログアウト・失効・アカウント停止等の影響を受けます。端末保存の閲覧許可は最後のオンライン認可から7日間です。ログイン保持期限と保存期限は別です。権限失効と到達不能も別として扱います。

メタデータ・表紙の保存は本体ダウンロードではありません。アプリ削除、ブラウザーデータ削除、アカウント/接続先変更による影響は[端末保存](../user/downloads.md)を確認してください。暗号化保存はDRMやサーバーの災害復旧用バックアップではありません。

## 上限の探し方

利用者が変更できる上限は[設定一覧](configuration.md)、プロトコル上の上限は[API](../api.md)、端末内部の整合性検査・キャッシュ上限は[端末保存設計](../design/offline-sync.md)に分けています。内部の受理上限を、利用者が確実に保存できる容量として案内しません。
