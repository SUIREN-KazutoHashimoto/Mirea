# 転送状況と表紙の変更

> このページは旧リンクからの案内です。Mirea `1.0.0`の手順は、以下の利用者ガイドにまとめています。公開版ごとの変更は[リリース履歴](../RELEASE.md)を参照してください。

転送は「送信すること」、後処理はサーバー上で表紙や再生用データを作ることです。フォルダを追加した場合も作品単位で進捗を確認します。

- 転送状況の「進行中」「要確認」「完了」「後処理」で段階を分けます。
- 「詳細」から追加先・進捗を確認し、権限がある追加先は開けます。
- 「要確認の記録をすべてクリア」は表示を整理するだけです。原本・作品・ジョブを削除する取消操作とは異なります。
- メニューを閉じても転送は続きます。ブラウザー自体の終了後まで送信できるという意味ではありません。

カスタムサムネイルはJPEG・PNG・WebPの静止画像、5 MiB以下です。元画像を保持し、縦横比を変えず長辺1,024px以下のWebPへ変換します。再生成時もカスタム原本を優先します。画像書籍の1枚100 MiBという上限とは別です。
