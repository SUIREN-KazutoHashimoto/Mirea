# シリーズ管理

シリーズは1本棚内のアセットの順序付きグループで、同じ本棚内のシリーズを子として含められます。最大16階層で、循環・自分自身の子・本棚をまたぐ親子関係はAPIとDBで拒否します。本（PDF・複数画像）・動画を混在可能。アセットは単独、または最大1シリーズに所属します。シリーズをまたぐ再利用・複数本棚を横断するシリーズは対象外です。移し替えるときは元のシリーズから外して保存し、新しいシリーズへ追加します。

## 画面と権限

- シリーズを開いて「シリーズを編集」で、親／子シリーズ・名前／説明・アセット追加／解除・矢印による順番変更・巻話ラベルを設定。追加候補は複数選択・すべて選択でまとめて追加し、「保存」で同じトランザクションに反映する。
- アップロード画面で既存シリーズへの追加、または新シリーズの作成（親も選択可能）と追加をまとめて指定できる。選んだ全アセットに適用し、サーバーの後処理の完了順で末尾へ追加。画面を閉じても所属指定は残る。追加先の削除・満杯などで入れられない場合、作品を単独で保存して警告する。新規作成の再試行は同じrequestIdを使い重複を避ける。
- 並び順と表示ラベルは別です。「第10巻」「外伝」「特典映像」も使え、タイトルの数字やアップロード順から自動推定しません。
- ライブラリはフォルダー型の階層表示。シリーズを開くと直下の子シリーズと直接所属する作品を表示し、戻ると親へ戻る。検索には親から子までのシリーズ名と巻話ラベルも含める。連続再生／閲覧の順番は直接所属する作品の設定順で、子シリーズへ自動的には踏み込まない。
- 閲覧中は最新のシリーズ情報を取得し、前／次・一覧選択で移動。通常の手動移動では動画は自動再生せず、それぞれ本人の続き位置を復元します。連続動作は以下のとおりです。
- 本棚の管理者／編集者だけが編集・削除可能。所属者全員が閲覧可能。未所属404、未認証401、閲覧者の変更403。
- シリーズに別の公開設定はありません。閲覧・配信・暗号化ダウンロードの認可は常に本棚所属を再確認。オンライン時は最新の認可を使い、オフラインは既存の7日間の端末許可に従います。シリーズ順の最新確認にはサーバー接続が必要です。
- 閲覧記録と続き位置はアセット単位のまま。他のメンバーの進行度をシリーズAPIで公開しません。シリーズ単位の分析集計は未実装です。

削除画面では「シリーズだけを削除する」と明示します。子シリーズは最上位へ移し、アセット本体・サムネイル・閲覧記録・続き位置・暗号化ダウンロードの登録や端末内データは維持します。アセット本体を削除した場合は、その所属だけを自動解除します。

## 連続再生・閲覧

ビューアーの「連続再生・閲覧」は初期ONで、変更は現在の画面のログイン中だけ保持します（ログアウト／再読込で初期化）。OFFでも通常の前後ボタン・アセット選択は利用できます。

- 動画はプレーヤーの実際のendedイベントで5秒のカウントダウンを開始。「自動移動を停止」「今すぐ次へ」で操作可能。メタデータ読込・進行度復元・一時停止だけでは開始しません。シーク・再生し直し・エラーでも待機を取り消します。
- PDF／画像本は最終ページの次操作で次のアセットへ進みます。次ページボタンは「次の作品 →」となり、下部にも継続ボタンを表示。右矢印／PageDownでも同じ動作です。最後のページを表示しただけでは進みません。読書時間の推定・自動ページ送り・複数冊の事前一括復号はしません。
- 連続移動先は先頭（動画0秒、本1ページ・幅に合わせる）から。動画なら自動再生を一度だけ試み、端末／ブラウザーに拒否された場合は手動再生の案内を表示します。既存の途中位置は実際に再生／表示するまでは上書きしません。最初にライブラリから開く場合と通常の前後ボタンでは、保存済みの続き位置を使います。
- 動画→本、本→動画、本→本、動画→動画の混在に対応。シリーズの最後では停止し、先頭へのループや別シリーズへの自動ジャンプは行いません。
- 切り替え直前にシリーズ情報を再取得し、その時点の順番を使います。シリーズそのものの変更／解除、権限失効、通信エラーでは現在の画面で停止し、別のアセットへスキップしません。失敗後は手動操作で再試行できます。
- 次へ移る前に進行度の保存を試み、現在のビューアーを閉じて閲覧記録・プレーヤー・復号鍵を解放してから次を開きます。次のアセットも既存の認証／配信処理を通り、暗号化保存済みの作品も、既存のオンライン認可／7日間のオフライン許可の範囲内で開きます。取得・自動再生失敗を閲覧済みと捏造しません。
- OFF・待機取消・画面を閉じる・非表示・ページ離脱・Androidバックグラウンド移行で自動移動を停止します。通信や進行度保存を待っている途中でも、取り消された古い処理から遅れて移動しないよう世代を検査します。戻っただけでは自動移動を再開しません。

連続動作はクライアント側の制御で、サーバーの権限・DBスキーマは変更しません。音声付き自動再生の許可はブラウザー／Android WebViewの設定と利用状況に依存します。制限を無効化したりミュートに切り替えて回避する実装ではありません。

## API

すべて `/api/v1` 以下。Bearer認証必須。応答には個人識別子・他人の進行度を含めません。

- `GET /shelves/:id/series` → `{series:[{id,shelfId,title,description,revision,createdAt,updatedAt,assetCount,coverId}]}`。先頭アセットの既存サムネイルをカバーに使えます。空グループはcoverId:null。
- `POST /shelves/:id/series` 本文 `{title,description?,parentId?,requestId?}` → 201 `{series,items:[]}`。revisionは1。
- `GET /series/:id` → `{series:{…,role},items:[{…item,series:{id,title,position,label},progress}]}`。positionは現在の表示順（1始まり）。progressは要求者本人だけ。
- `PUT /series/:id` 本文 `{revision,title,description,items:[{assetId,label?}],parentId?,children?:[seriesId]}` → 更新後の詳細。配列順を保存し、省いたアセットを解除します。親と子の指定を省略した旧クライアントの更新は既存階層を維持します。childrenを指定した場合、省いた直下の子は最上位へ移します。変更全体を同一DBトランザクションで反映します。
- `DELETE /series/:id` 本文 `{revision}` → 204。シリーズのみ削除。
- `GET /items/:id/series` → 詳細に `currentIndex`（0始まり）を追加。未所属なら `{series:null,items:[],currentIndex:-1}`。
- `GET /shelves/:id/items` は全シリーズの概要と、各アセットのseries（未所属はnull）を含みます。

名前は空白のみ不可・200文字まで、説明2,000文字、巻話ラベル80文字、最大1,000アセット、編集本文256 KiB。重複アセット・異なる本棚・存在しないアセットは422、他シリーズ所属は409です。本棚外のアセットの名前等はエラーに返しません。シリーズ名の重複は許可し、IDで区別します。

更新／削除のrevisionが最新でなければ409。別画面での変更を自動マージせず、画面にエラーを出します。「保存せず最新の内容を読み直す」で明示的に再読込してください。応答を受け取れなかった編集も再読込して成否を確認します。同じPUTを再送しても古いrevisionでは反映しません。

アセット削除による所属変更でもrevisionを増やします。内部の順番に欠番ができてもAPI／前後移動は残った順番で連番表示し、次の保存で詰め直します。本棚をまたぐ所属はDBトリガーでも拒否します。

## 運用

DBスキーマv16への追加マイグレーションです（親ID・アップロードの所属指定・作成要求IDの追加）。既存シリーズは最上位のまま保持します。既存メディア・本人の進行度・無期限分析ログ・暗号化ダウンロードとマスター鍵を保持します。従来どおりDATA_DIR全体を一貫した状態でバックアップしてください。WebとAndroidは共通UI／APIで、直接起動とコンテナで挙動は同じです。
