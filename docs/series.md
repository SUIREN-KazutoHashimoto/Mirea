# シリーズで作品をまとめる

> このページは旧リンクからの案内です。Mirea `1.0.0`の手順は、以下の利用者ガイドにまとめています。公開版ごとの変更は[リリース履歴](../RELEASE.md)を参照してください。

シリーズは同じ本棚内の作品をまとめるための入れ物です。最大16階層まで子シリーズを作れます。同じ親の下に同名のシリーズは作れず、別の親の下なら同名を使えます。

「シリーズを編集」では作品の検索とまとめ追加、巻・話ラベル、名前順・手動順を設定します。別シリーズからの移動や大量候補の分割表示も扱います。作品の所属は一つのシリーズだけです。複数の選集に入れたい場合はプレイリストを使います。

| 削除時の選択 | 結果 |
| --- | --- |
| シリーズだけを削除 | 子シリーズと作品を残す |
| 配下のシリーズ・アセット・原本も削除 | 確認画面に示された範囲を削除。元に戻せない |

フォルダ取り込みでは同じ階層に同名の既存シリーズが一つある場合、それを再利用します。削除・上書き・勝手な重複統合はしません。
