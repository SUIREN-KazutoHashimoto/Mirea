# 0.15.2beta ライブラリ管理

## 一覧・表紙の一括保存

「全アセットの一覧・表紙を保存」は、現在の絞り込みに関係なく、本人が所属する全本棚のアセット基本情報・サムネイル・本棚・シリーズ階層・本人のプレイリストを端末へ保存します。メディア本体や他人の閲覧ログは取得しません。ZIPのエクスポートではなく、オフライン一覧の暗号化キャッシュです。

通常の自動同期も継続します。一括保存はサムネイルを3件ずつ再取得し、転送状況と画面に件数・失敗数を表示します。停止・通信失敗・容量不足でも取得済みは保持し、再実行できます。ログイン先／アカウント変更で旧アカウントの保存処理を停止します。期限は最後の接続から7日で、ログアウト時の鍵無効化は従来どおりです。OSの強制終了やブラウザー終了を越える常駐実行は保証しません。

## ソート

追加日時の昇降順、自然順のタイトル昇降順、サイズ昇降順、未完了を優先する続き位置更新順を選べます。シリーズ内とプレイリスト内では「設定した順」も選択可能です。シリーズカードのサイズは子シリーズを含む作品の合計。閲覧履歴だけは最後の閲覧順を維持します。ソートは表示だけを変更し、シリーズの連続再生順は変更しません。

## プレイリスト

左メニューの「プレイリスト」を開くと、通常のコンテンツ一覧と同じカード／リスト表示で個人リストを表示します。開いたリストに個々のアセットが並び、表示形式・検索・種類・ソート・一括ダウンロードを利用できます。作成・名前変更・まとめて選択・上下の並び替え・解除は一覧内の編集画面で行います。作品の長押し／右クリックメニューから既存リストへ追加もできます。

1人200リスト、1リスト1,000作品。同じ作品を複数リストに追加できます。本棚やシリーズの所属は変更しません。リストの共有・リスト専用の連続再生順は含まず、再生・閲覧は元アセットの既存機能を使います。

サーバーが毎回本人所有と本棚の閲覧権を確認します。他人のリストを操作できず、権限を失った作品は一覧・オフライン同期から除外します。元アセットの削除で参照が消え、リストの削除は元アセットを削除しません。端末上の一覧もアカウント／サーバー別に暗号化保存します。

## フォルダの一括アップロード

アップロード画面の「フォルダを丸ごと選択」から選択します。最上位フォルダもシリーズとして作成し、下位フォルダを子シリーズ、各ファイルを個別アセットにします。フォルダ内の画像は1ファイル1冊です。従来の通常ファイル選択では複数画像を1冊にまとめる動作を維持します。

選択した既存シリーズ／作成した新シリーズは、フォルダツリーの親になります。同名の既存シリーズとは自動統合しません。空フォルダは対象外。最大100ファイル・300フォルダ・16階層（既存の親を含めたサーバー上限も16階層）。非対応形式、空ファイル、危険な相対パス、同一路径の重複、サイズ超過はアップロード前に拒否します。

フォルダは階層順に作成し、作成要求IDを再利用して同じ画面内の再試行で重複を防ぎます。後続の失敗時に既に作成済みのシリーズ／アセットを自動削除しません。必要なら成功分を確認して整理してください。アセットの送信・後処理は既存の最大3並行、原本保持・権限検査・分割転送・背景転送を利用します。

Webは対応ブラウザーのディレクトリ選択、Androidは[Storage Access Frameworkのフォルダ選択](https://developer.android.com/training/data-storage/shared/documents-files#grant-access-directory)を使います。全ストレージ権限は追加しません。Android側の新しい選択機能と同梱画面は新APKへの更新後に利用可能です。今回の依頼はPR・マージまでで、署名済みAPKやコンテナの新規公開は行いません。

## 更新・復旧

DB v17→v18は個人リスト用2テーブルとインデックスの追加だけで、既存のアカウント・本棚・シリーズ・作品・閲覧記録・進行度・暗号鍵は保持します。更新前に停止中のDATA_DIR全体と設定を退避してください。MEDIA_DIRを分離している場合は対応する本体領域も保護し、復旧は旧コードと更新前データを組で戻します。旧0.15.1はv18を開けません。
