# 一覧・プレイリスト・フォルダ取り込み

> このページは旧リンクからの案内です。Mirea `1.0.0`の手順は、以下の利用者ガイドにまとめています。公開版ごとの変更は[リリース履歴](../RELEASE.md)を参照してください。

一覧の表示、作品のまとまり、端末への保存は別々に選べます。

| やりたいこと | 操作 |
| --- | --- |
| 多くの作品を探す | タイトル検索、種類・ソート、リスト表示 |
| 表紙を並べる | 2列・3列・5列表示。必要なら「サムネイル＋タイトル」 |
| 本棚内で階層を作る | シリーズと子シリーズ |
| 本棚をまたぐ自分用の選集を作る | 同じ種類の作品をまとめたプレイリスト |
| PCのフォルダ構成を取り込む | コンテンツ追加のフォルダ選択 |
| 通信しにくい場所で一覧を確認する | 設定から一覧・表紙を保存 |

一覧のソートと、シリーズ・プレイリストの再生順は別です。プレイリストへの追加は元作品の所属を変えません。保存されるのは参照であり、作品本体を端末に取得する操作ではありません。
