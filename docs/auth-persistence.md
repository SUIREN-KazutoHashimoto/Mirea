# ログインの保持と端末保存

> このページは旧リンクからの案内です。Mirea `1.0.0`の手順は、以下の利用者ガイドにまとめています。公開版ごとの変更は[リリース履歴](../RELEASE.md)を参照してください。

同じ端末ではログインを通常30日間保持します。ログアウト、パスワード変更、セッション失効、ブラウザーの保存データ消去などで、それより早くログインし直す場合があります。

端末保存の閲覧期限は別に管理します。ログインが残っていても、最後の有効な権限確認から7日を超えた作品を通信なしで開くことはできません。逆に、接続できないことだけを理由に有効な保存データを消去する必要はありません。

Web/PWAはCookieなどのブラウザーの認証機構、Androidはプラットフォームの保護された保存機構を使います。本人のパスワードを自動ログイン用の平文ファイルとして保存する手順はありません。通信保護と端末保護の詳細は設計書を参照してください。
