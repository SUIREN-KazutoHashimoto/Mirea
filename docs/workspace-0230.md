# 画面・転送・診断の変更（0.23.0beta）

Web/PWAの左上のロゴからMireaのバージョンとプロジェクト情報を開けます。ライブラリへファイルをドロップすると追加画面で選択済みになります。「アップロードする」を押すまで送信しません。送信待ち・送信中のファイルがある間は、タブ終了・再読み込み・別ページへの移動時にブラウザー標準の確認を表示します。確認文や確認を省略する条件はブラウザーが管理します。送信済みでサーバーの後処理だけが残る場合は確認しません。

プレイヤーの操作メニューは通常、コンテンツの上に重ねます。固定ボタンを有効にすると、メニューや操作パネルの場所を確保してコンテンツを表示します。固定状態は連続再生中も維持します。動画・音声の操作はアイコンと読み上げ名で示し、速度・画質などは必要なときに開きます。

通常順の連続再生では次の動画・音声を、再生や閲覧回数を記録せずに先読みします。実際に移る直前にアクセス権を再確認し、保存データは既存の7日間の視聴許可を確認します。アカウント・接続先・認証状態が変わると先読みを破棄します。Androidはメモリに余裕がある端末で残り45秒から準備し、シャッフル・単体リピート中は別作品を準備しません。回線・端末の能力により待ち時間が発生する場合があります。本は表示中のページを残したまま次ページを描画します。

終了後に再び起動すると、直前の再生を停止中のミニプレイヤーとして復元します。自動再生はしません。アクセスできる作品だけを復元し、再ログイン時もアカウントと接続先を区別します。

転送状況は「進行中」「要確認」「完了」「後処理」に分けます。「要確認の記録をすべてクリア」は転送一覧の表示だけを整理し、アセット・原本・ジョブは削除しません。再試行で状態が変わった場合は再び表示します。経過時間と終了予想は進捗から計算し、処理の内容によって変動します。旧版で時刻を記録していなかった履歴の時間は推測して表示しません。

設定の「記録と診断」から、現在の画面で発生した最大20件のエラーをまとめてサーバー管理者に送れます。操作しなければ送信しません。サーバーでも許可した項目だけを取り出して保存します。作品名・ファイル名・メール・認証情報・URL・絶対パス・例外の原文は保存しません。管理者は「エラー報告」で送信単位に確認・コピーできます。

プレイリストには音声・動画・本のいずれか一種類をまとめます。PDF・EPUB・画像書籍は同じ「本」です。既存の種類が混在するリストは削除・自動変更せず、手動で整理するための案内を表示します。プライベート本棚のアセットは閲覧履歴一覧に表示しません。進行度や分析用記録は保持します。

## 管理画面のサーバー設定

初期値は、アセット2GiB、転送の分割8MiB、新規登録許可、閲覧記録の収集有効です。管理者は「サーバーの設定」で変更でき、再起動後に適用します。環境変数が指定されている場合はその値を優先し、入力欄に変数名と値を表示します。保存値はDBに含まれ、環境変数を取り除くと保存値が使われます。

| 管理画面 | 優先する環境変数 |
| --- | --- |
| アセットの容量上限 | `MAX_UPLOAD_BYTES` |
| 分割転送サイズ | `UPLOAD_CHUNK_BYTES` |
| 新規登録の許可 | `ALLOW_REGISTRATION` |
| 閲覧記録の収集 | `ANALYTICS_ENABLED` |
| 同時送信・各種後処理・一括選択の上限 | `MAX_CONCURRENT_UPLOADS`、`MAX_CONCURRENT_JOBS`、`MAX_CONCURRENT_THUMBNAILS`、`MAX_CONCURRENT_PREVIEWS`、`MAX_CONCURRENT_INGEST`、`MAX_UPLOAD_ASSETS` |

同時処理数は保存後、待機中・新規処理から反映します。設置に依存する待受アドレス／ポート、DATA_DIR／MEDIA_DIR、TLS／CA、CORS、FFmpeg／FFprobeの実行場所、署名鍵、管理者の初期設定、更新配布元・専用ヘルパーの場所は設置環境で管理します。Webサービスから権限・公開範囲・証明書や秘密鍵を書き換える機能は追加しません。

DBスキーマは24です。移行前に完全バックアップしてください。既存のメディア・利用者・閲覧記録・進行度・ダウンロード鍵・APK署名・証明書は保持します。

## 検証範囲

合成アセット・一時DB・新規ブラウザープロファイルで、デスクトップ／小画面／スマホ縦横、操作パネル固定、同じ画面での連続再生、保存データ、通信切替、設定・転送・診断報告を検証します。Androidは単体・ライフサイクル・先読みの認証分離テスト、画面描画とlintを実施します。実機Androidの動作やPlay Protectの判定を保証する検証ではありません。TrueNASの利用者データは検証に使用しません。
