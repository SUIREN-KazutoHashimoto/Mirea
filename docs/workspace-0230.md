# 画面・転送・診断の案内

> このページは旧リンクからの案内です。Mirea `1.0.0`の手順は、以下の利用者ガイドにまとめています。公開版ごとの変更は[リリース履歴](../RELEASE.md)を参照してください。

このURLは以前の版の変更説明に使っていました。現在の手順は用途別に整理しています。

| 用途 | 現行の案内 |
| --- | --- |
| ロゴから版を確認、初回起動 | [はじめに](user/first-steps.md) |
| ファイルのドロップ、転送・後処理、誤って終了しないための確認 | [アップロード](user/uploads.md) |
| メニュー固定、連続再生、次の作品の準備 | [再生・閲覧](user/playback.md) |
| プレイリスト・一覧形式 | [ライブラリ](user/library.md) |
| マスク済みエラーを運営へ送る | [プライバシーと診断](user/privacy.md) |
| 環境変数と管理画面の優先関係 | [管理者の設定](operations/settings.md) |

転送状況の記録をクリアすることと、作品・原本を削除することは別です。診断送信は本人の操作で行い、詳細な閲覧記録の書き出しとは分けて扱います。
